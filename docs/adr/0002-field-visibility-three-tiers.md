# 字段可见性三级：完全公开 · 小组公开 · 完全私密

可分享性落在字段级，不在文件级。一支舞的标注可以来自队友，而队友之间的进度对照要求逐段熟练度随包走——文件级二分挡不住这件事，分享与备份又本是两个收件人不同的动作。

三级分级是：**完全公开** = 标注方案的全部标注字段——首尾边界、分段线、半拍线、学习段重点、局部镜像片段、备注贴纸、舞者名册、歌曲署名、封面帧位置、节拍网格与节拍矫正（整曲**节拍倍频**与逐段**段内倍频**），任何 susume 包都可含；**小组公开** = 现为逐段熟练度，只有勾选时才进包；**完全私密** = 激活状态、编辑偏好、浮层几何、练习侧取景、练习片段列表、素材自动删除策略、续播位置、署名缓存与最近打开、计划数据、练舞统计与四拍桶明细、设备级设置，一律不进分享包。

分级只管分享：完全私密字段仍随**备份**走——备份的收件人是用户自己。媒体文件不占等级：源视频副本与练习录像由每次分享的勾选与各入口默认值决定；封面图片是设备本地缓存，既不进分享包也不进备份。**「小组公开」不是访问控制**：没有身份、没有服务端，分级表达的是「这次的包带不带它」，不承诺任何强制力。

「本地文档」承载的字段里既有完全私密也有小组公开——名字说的是它不随分享走，不是「内容都私密」。

## Considered Options

- **新开一个「小组文件」作第三个存储位置**：统一不了任何东西（熟练度在本地文档、练习录像在素材目录），只会成为第三个地方，并破坏「段与写入者一一对应」。
- **加档位（四级、五级）**：级数增加的是措辞成本，不是表达力；现有三级的差别各自对应一个具体动作。
- **服务端身份与访问控制**：本地阶段不建网络层与账号。

## Consequences

- 熟练度一旦可随包走，就回不到「永不流出」——这是三级分级最贵的一处代价，已接受。
- 备份成为完全私密字段唯一的出口，其完整性直接决定换机是否丢数据。
