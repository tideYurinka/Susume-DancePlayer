# Trademark Guidelines

These guidelines apply to the Susume name, logo, icons, visual identity:

- `assets/brand/app_icon_1024.png`
- `android/app/src/main/res/mipmap-*/ic_launcher*`

The source code of Susume is licensed under the GNU General Public License v3.0
(see LICENSE). It does not grant trademark rights.

## Permitted Uses

You may:

- Refer to Susume by name when describing compatibility, attribution, or that a
  project is based on Susume.
- Use phrases such as "forked from Susume", "based on Susume", or "compatible with
  Susume" when the relationship is accurate.
- Link to the upstream Susume repository and documentation.

## Uses That Need Permission

You need prior written permission to:

- Use the Susume name, logo, or icons as the primary name or identity of a fork,
  distribution, hosted service, or commercial product.
- Present a fork or derivative work in a way that suggests it is official,
  endorsed, sponsored, or maintained by tideYurinka.
- Register domains, social accounts, packages, apps, or marketplaces names that
  are likely to confuse users about whether they are official Susume properties.
- Use Susume brand assets in paid advertising, product packaging, or hosted
  service branding.

## Forks And Derivative Products

Forks should use a distinct product name and distinct visual identity. They
must preserve the applicable license files and NOTICE file, and should clearly
state that they are independent from upstream Susume unless a separate written
agreement says otherwise.

between this document and the GNU General Public License v3.0 (LICENSE), the
GPL-3.0 controls software license rights and this document controls brand usage.
