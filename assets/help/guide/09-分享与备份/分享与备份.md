# 分享与备份

分享一支舞的标注方案、收到别人的方案，以及备份与恢复整机数据。

## 分享

舞详情页「⋯」→「分享」。勾选要随包带出的东西，确认后把包交给系统分享面板，由你选择发给谁。

- 「带源视频」：把源视频副本一起带走，对方没有这支舞也能直接练
- 「带熟练度」：接收者可以看到你的熟练度，
- 「带练习录像」：接收者可以看到你的练习录像

### 分享视频（mp4）

舞详情页「⋯」→「分享视频（mp4）」

把源视频副本当普通 mp4 直接递出，不打包(对方没装 Susume 也能看)

### 接收别人的标记方案

一支舞除了保存自己练习用的标记方案，还可以导入别人的标记方案：
1. 在QQ/微信下载后缀为susume的文件
2. 点进文件
3. 点击分享->分享到其他软件
4. 选择Susume

### 使用场景解读

小组内分享
1. 组员分享时勾选「带熟练度」、「带练习录像」
2. 分享到小组的QQ群/微信群
3. 组长接收时选择「留成TA的方案」
4. 给TA备注名字
5. 在舞详情页点击组员的方案，即可查看对方的熟练度和练习录像


## 备份与恢复

- 备份：首页「⋯」→「备份」。把整机数据做成一个 susume 文件，包含所有标注方案、私密设置、统计明细。

- 恢复：首页「⋯」→「恢复备份」，选择，确认后会替换本机所有数据。勾了媒体的包把源视频与练习录像解回本机；没带媒体的舞恢复后源视频是空的，重新导入同一支视频即可接回。

>替换数据前会对本机数据做一次备份，备份文件会保存到应用目录「备份留档」，可手动清理。
