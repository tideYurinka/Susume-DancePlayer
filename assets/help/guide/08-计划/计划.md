# 计划

用一年时间轴、月历与日程列表安排练舞计划，随舞、团检和各舞截止（DDL）都在这里。

## 计划页

底部导航栏的「计划」进入计划页。页面上到下依次是：

- 一年时间轴条：从当前月起铺 12 个月，有计划的日子按类型画竖线，卡内一行图例写出三类各自的颜色——`舞 DDL` / `随舞事件` / `团内检查`。点某个年月列即把日历切到那个月。
- 月视图日历：以周一为首列铺当月网格，有计划的日子在数字下方出对应颜色的圆点；左右按钮与网格左右滑动都能翻月，翻到不是当前月的月份时标题旁出现「今天」。点某一天即选中它（选中日描边），下栏随之出现。
- 点某天后的下栏：标题右边是「当日练习」与该日累计时长，下面有「新建随舞」「新建团检」两枚入口，再往下列出当天到期的舞（可点进舞详情）；当天没有舞到期时写「这天没有到期的舞」。

## 日程列表

计划页底部是日程列表，按三组分列，空组不占位：

- `即将到期`：快要到期的 DDL 与团检，逐行写目标与「剩 N 天」（当天写「今天到期」）。
- `待复习`：久未练或熟练度偏低的舞，点了进舞详情。
- `随舞临近`：临近的随舞事件，逐行写日期与关联舞数量，点了进编辑框。

## 随舞与团检

点下栏的「新建随舞」「新建团检」进全屏编辑页。两者共有的字段是日期、`提前 N 天提醒`（滚轮选择，首档「不提醒」）与 `备注`。

随舞另有 `开始时间`（时列首档「不设」）、`名称 / 地点`、`关联舞`勾选清单，以及可加项、打勾、删除的 `准备清单`。

团检另有 `检查方式`（`到场排练` / `录视频提交`）与逐支舞的达标门（`掌握` / `较熟` / `不设`，默认「较熟」）。选「录视频提交」后可勾「已提交」并填提交日期。

## 各舞计划

计划页右上角进「各舞计划」管理页：所有舞按有没有计划分组，可搜索标题、只看未设计划，逐支舞编辑。

舞详情页尾也有「计划」区，用来给这支舞 `设截止（DDL）`：填日期、场合、备注、`提前 N 天提醒` 与 `准备清单`，设好后可「编辑」「清除」。这里还能关掉「随舞曲库」（关掉后新建随舞不再默认带上这支舞）与「复习提醒」（关掉后不再给这支舞发复习提醒，计划 Tab 的红点不再为它亮）。

## 计划数据的存放

计划只存在本机，不会随分享包发给别人，只跟着备份走。
