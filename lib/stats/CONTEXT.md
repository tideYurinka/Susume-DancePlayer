# 统计与计划 — Context

练舞的记账与汇总，以及练到什么时候的日程——练习时长与四拍桶、连续天数、熟练度档位、目标与复习提醒。

## Language

**练舞统计**:
有效练习区间内实际播放时间的自动记录（墙钟时长，倍速不折算；暂停/拖动不计），按本地日聚合、按舞（署名快照）可读，明细记账单位见「四拍桶」；**完全私密**，存于全局本地统计文件（practice_stats.json），随**整机备份**走、不随任何分享包。
_Avoid_: 打卡、时长记录

**练习场次**:
练舞统计的计数单位：一次连续练习记一场，即一条会话记录（同日、同舞、同署名、间隔 5 分钟内的播放并入同一场；跨零点按午夜拆条）。某天的场次 = 当天全部舞的会话记录条数之和；某支舞的场次 = 该舞在所选窗口内的记录条数。它由**练舞统计**的会话记录派生，不新增存储。界面上一律写作「次数」。
_Avoid_: 不要用「次数」指这个领域概念本身

**练习记账**:
哪一段播放进入练舞统计的判定：按**播放语境**逐值声明计与不计（观看/编辑/待命/对比/取景/回看/录制准备/延迟预备…），判定只由**事实**推出——会话模式、录制相位、练习片段回看在飞、引擎播放态。不计的语境自判定翻转点起结算，其后的播放时间掐掉。只回答「计不计」；记多细与口径（倍速不折算、暂停不产区间、四拍桶）见「练舞统计」「四拍桶」词条。
_Avoid_: 记账门、统计门（实现层措辞）、排除集/排除计数（那是实现形态，不是概念）

**四拍桶**:
练舞统计的明细记账单位：播放时按节拍网格把位置换算成**绝对四拍序号**（**第 N 根四拍线**，自整曲首个强拍起数，与八拍锚点无关）；一个桶 = 相邻两根四拍线之间的四拍区间，键 = 左侧那根四拍线的序号。每扫过一个桶累加墙钟秒与扫过次数——**扫过** = 播放头连续推进越过该桶右边界（暂停/拖动/翻看不计、倍速不折算、循环每圈重复累加；跳变与回退处断开，不跨越中间桶、不回补）；记录与用户分段线无关，展示时按当前分段线聚合成「段」（移动分段线只换分组、历史不回改；桶整体归其左边界所在的段）；节拍网格未就绪（占位/异常）时不产桶、只记总时长。桶键带**记录时的倍频身份**：「节拍倍频」改变桶格时**不改写磁盘**，由读取时按每条记录自己的倍频重建当时桶格、换算成绝对时间区间后归入当前桶格再聚合（墙钟秒守恒——细分为均分、合并为求和；扫过次数——细分为复制、合并取最小），故历史一段音乐都不丢，总练习时长（来自会话记录、非桶求和）不受影响。桶格恒取**节拍倍频**（整曲档），**段内倍频**不改写桶格也不进桶键。
_Avoid_: 八拍桶（旧口径，已废弃——桶键曾定为八拍大线且未定义与锚点的关系）、四拍中线（旧措辞，线在拍点上、不在拍间取中）、四拍（那是节拍计数单位）、段（那是展示分组）

**段练习次数**:
一段被**完整经过**的遍数（从段首播到段尾 = 一遍：循环练习每圈 1 遍、顺播经过 1 遍），由段内各四拍桶扫过次数推导（取段内桶扫过次数最小值）；区别于「平均练习遍数」（时长折算的宏观指标）。
_Avoid_: 遍数（单独使用时含义模糊）、练习次数（口语，规格内统一为段练习次数/平均练习遍数/练习场次）

**段练习时长**:
一段内各四拍桶墙钟秒之和，随当前分段线聚合（移动分段线只换分组、历史不回改）；桶整体归其左边界所在的段，故段界切在桶内时该桶的时长整段归前一段。
_Avoid_: 段时长（会被读成段本身的跨度）、段跨度（那是尾−首）

**平均练习遍数**:
单支舞的宏观练习指标：累计墙钟练习时长 ÷ 当前有效区间时长（尾−首），随首尾线调整实时重算；与「段练习次数」（扫过计数）口径不同、可并存展示。
_Avoid_: 遍数（那指段级完整经过计数）

**当前连续天数**:
练舞统计的一项汇总指标：在「当日练习时长 > 0 秒」的本地日集合上，以**今天**为终点向前的连续日长度；今天没练即为 0。它与「最长连续天数」互为对照——前者是当下状态，后者是历史最长。
_Avoid_: 连续天数（单独使用时含义模糊）

**最长连续天数**:
练舞统计的一项汇总指标：在「当日练习时长 > 0 秒」的本地日集合上求最长的一段连续日；它是历史最长，不因某天没练而回退。
_Avoid_: 连续天数（单独使用时含义模糊，请说「当前连续天数」或「最长连续天数」）

**有目标**:
某支舞是否存在待处理的目标：存在未过且未落档的 DDL，或关联了未到日的团内检查 / 随舞事件；已逾期、已达成、已清除的不算。它是复习提醒与静默的判定口径——完全掌握且无目标为静默，出现新目标即重新开启。
_Avoid_: 进行中（口语，规格内统一「有目标」）、待办（那是应用内提醒项，不是舞的状态）

**复习提醒**:
每支舞可单独开关的应用内提醒（默认开）：按当前熟练度档位给遗忘阈值——掌握 30 / 较熟 14 / 能跟上 7 / 学习中 3 / 未练 3 天未练触发一次，触发后进入冷却，直到该舞再被练习或档位变化才重新计时；只有「有目标」的舞参与，逾期项不提醒。
_Avoid_: 催练（口语）、遗忘提醒（同义外文直译，规格内统一「复习提醒」）

**团内检查**:
日历事件类型（排练与交作业合并为一类）：日期 + 关联舞清单 + 每舞达标门 + 检查方式（到场排练 / 录视频提交）；录视频提交类（交作业）带手动「已提交」标记与日期，到场排练类不需提交。
_Avoid_: 交作业事件、排练事件（分立称呼，两者同属团内检查）

**达标门**:
团内检查事件对某支关联舞的最低熟练度档位要求（默认较熟，可按事件调为 掌握/较熟/不设）；该舞全部学习段档位都达到该档即该舞达标，事件内各关联舞全部达标即事件达标；「不设」与没有任何学习段的舞不参与判定。
_Avoid_: 门槛（口语，规格内统一达标门）

**随舞曲库**:
每支舞的「是否参加随舞」开关（默认开）：开 = 该舞会去随舞跳，新建随舞事件时默认带入关联清单；关 = 冷门曲只自己练，不参与随舞事件关联与随舞临近提醒。
_Avoid_: 曲库（单独使用含义宽泛）

**随舞事件**:
日历上的真实随舞活动对象：名称（可选）+ 日期 + 可选时间/地点备注 + 关联舞清单（默认带入随舞曲库=开的舞、可逐支增删）+ 可选准备清单（逐项打勾）。
_Avoid_: 随舞（活动本体，事件是其日历对象）

**计划标记**:
计划页时间轴与月视图日历上「这天有安排」的记号，按类型分三类——舞 DDL（练熟期限）、随舞事件、团内检查，每类一个固定颜色；时间轴的竖线与日历的圆点同属一类记号，共用同一套配色。它只表达类型，不表达逾期 / 达成等状态（状态由首页角标与日程列表承载）。
_Avoid_: 事件（那指随舞事件与团内检查两类日历对象，不含舞 DDL）、标记（单独使用含义宽泛）
