# 分享与备份 — Context

标注方案与整机数据怎样离开这台设备、又怎样回来——susume 包、分享、备份、组员方案与问题日志包。

## Language

**标注方案**:
一套完整的标注及其配套数据——视频首/尾边界、分段线、半拍线、学习段重点、局部镜像片段、源画面取景、备注贴纸、舞者名册、歌曲署名、节拍网格与人工修正，外加可选的**逐段熟练度**（小组公开级）。它是「分享」「导入」与「备份」的粒度单位。一支舞恰有一个**可写的「我的标注方案」**（即公开标记文件与本地文档所描述的那一套）与若干**只读的「组员方案」**；首页与舞详情要的派生量一律取我的标注方案。
_Avoid_: 配置文件（会与「公开标记文件」「本地文档」这三个"文件"混指）、方案（单用含义含糊）、标注集、主标注方案（不是独立概念——我的标注方案即是）

**组员方案**:
导入得来的**只读**标注方案，附发送方那一次的熟练度快照与本机设定的**组员名**（导入时设定，发送方填过则预填）。舞详情页的方案区把它与「我的标注」并列成行，点一行即以那一份方案进入播放——**方案是打开播放时的一个参数**。只读落在两层上：装载它时底部标注工具槽**整排不出现**（组员方案态槽集），而手势与快捷键这些不经过底排的入口由标注编辑的门禁拦住——首尾边界/分段线/半拍线/局部镜像片段/备注的一切改动被拒，播放、跟跳、节拍与不落盘的临时衔接段照常。我的落盘学习段选中**不读也不写**（退出后逐位相同），我的续播位置**读而不写**（从上次练到的地方接着看，书签不动）。包里的**方案标识**相同即替换那一条、不同即新增一条。
_Avoid_: 外来方案（同义，项目内统一「组员方案」）、别人的方案（口语）、参考方案、队员方案

**susume 包**:
「分享」与「备份」的产物：单文件容器（zip），内含一份自述清单——**包格式版本、视频标识、方案名、方案标识、可选组员名**——以及按勾选带出的媒体（源视频副本、练习录像）。文件名 `<歌名>.susume`，未署名时回落视频文件名。**包格式版本不符时明确报错**，不静默降级：本机自己写的文档跨版本按空态丢弃，而用户主动拿来的包必须说清为什么读不了。
_Avoid_: 导出文件（那指成片视频，是另一件事）、压缩包（口语）、分享包（会与「备份」混指）

**分享**:
把**一支舞**的 susume 包交给系统分享面板，由用户选择递给谁；只含我的标注方案，不含组员方案。默认带源视频副本，熟练度与练习录像默认不带。可见性三级中，**完全公开**字段必定随包，**小组公开**字段由勾选决定，**完全私密**字段永不进分享包。素材库每行的「**发给小组**」是同一动作的第二个入口，默认带熟练度与该条练习录像、默认不带源视频。
_Avoid_: 导出（本项目没有「导出到指定目录」这个动作）、发送（口语）

**备份**:
把**整机数据**打成一个 susume 包：全部舞的我的标注方案与组员方案、以及**完全私密**字段（学习段选中、编辑偏好、浮层几何、练习片段列表、素材自动删除策略、续播位置、署名缓存与最近打开、设备级设置），含练舞统计（按天会话与四拍桶明细）；媒体默认不含、可选。产物经系统分享面板送出，由用户自己存放。**恢复 = 全量替换**本机数据，恢复前自动为当前数据留档。它是**完全私密**字段唯一的出口。
_Avoid_: 导出（同「分享」的避讳）、同步（那指服务器，本项目没有）

**问题日志包**:
用户在**帮助中心**「问题反馈」教程页点「**发送问题日志**」时当场产出的一份诊断快照——一条必答的问题描述与几个可选的结构化回答、一块应用运行日志正文（含崩溃与异常记录）、设备与版本信息，以及用户当场勾选的那些舞的**完全公开**字段（名称、视频标识与**公开标记文件**原文）。不含**完全私密**字段、不含媒体。它与**分享**（一支舞的标注方案）、**备份**（整机数据）、**导出**（成片视频）并列，是第四种产物；文件名 `susume-logs-<时间戳>.zip`。
_Avoid_: 分享包（会与「备份」混指）、日志文件、导出日志、诊断信息

**发送问题日志**:
「问题反馈」教程页里那个按钮的动作：进一个表单页（问题描述必答、几个结构化可选项、从全部舞里多选要附带的舞），确认后打包成**问题日志包**交给系统分享面板，由用户自己选择发给谁。问题描述为空时该钮置灰但按得动，弹一句「先说说遇到了什么问题」。应用内不留副本、失败不重试；包只经用户自己的手送出。
_Avoid_: 分享日志（那是「分享」一词的误用）、上传日志、导出日志

**可见性等级**:
每个**数据字段**的可分享性，三级——**完全公开**（标注方案的全部标注字段——首尾边界、分段线、半拍线、学习段重点、局部镜像片段、源画面取景、备注贴纸、舞者名册、歌曲署名、封面帧位置、节拍网格与节拍矫正（含**段内倍频**），任何 susume 包都可含）、**小组公开**（现为逐段熟练度，只有勾选时才进包）、**完全私密**（学习段选中、编辑偏好、浮层几何、练习片段列表、素材自动删除策略、续播位置、署名缓存与最近打开、计划数据、练舞统计与四拍桶明细、设备级设置；不进任何分享包，只随**整机备份**走）。分级只管**分享**；**媒体文件**（源视频副本、练习录像）不占等级，由每次分享的勾选与各入口的默认值决定。
_Avoid_: 隐私等级（那指加密与访问控制；本项目没有身份与服务端，分级表达的是"这次的包含不含它"）、公开/私密二分（三级取代它）
