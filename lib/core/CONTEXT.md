# 基础与画面 — Context

全 App 共用的口径——画面方向与取景选区、视口与朝向、命中盒/字号/对比度下限，以及播放器内核的寻址缝。

## Language

**画面方向**:
每一路画面（见词条**面**）此刻在屏幕上**朝哪一边**的口径：参照系是录像文件的原相，⊕ 表示水平翻转的合成，逐面取值——源视频 = 全局镜像 ⊕（局部镜像 ∧ 片段覆盖当前位置）；相机预览 = 练习镜像 ⊕ 平台预览基准 ⊕ 基准键；片段回放 = 练习镜像 ⊕ 平台保存基准；录像文件（指素材对象的方向）= 平台保存基准；导出文件 = 导出开关 ⊕ 平台保存基准。练习侧两路因此恒等且锚定在**平台保存基准**（本机 开 = 照镜子、关 = 原相），平台预览基准只作为相机预览面的自身原始朝向进入施加缩放。画面件按它套变换、注解层（备注贴纸）按它做坐标换算、辅助浮层（数拍数字、节拍动画）不参与；该面实际施加的翻转 = 自身原始朝向 ⊕ 本口径的取值。**源视频面那一条式子只有一处声明**：上屏按**位置**读它（当前显示位置落不落在片段内），**投屏渲染**按**区间**读它（片段表写成半开时间窗）——电视上的翻转与手机上实际显示的逐帧一致因此是同一个值的两种读法，不是两处各自对齐的纪律。
_Avoid_: 镜像次数（那是实现口径）、翻不翻（口语；取值是两个方向，不是布尔）、画面方向开关（开关各有专名）

**面**:
参与「画面方向」取值的一路画面——源视频 / 相机预览 / 片段回放 / 录像文件 / 导出文件（未来）；每面按其自带的口径合成，加一个面 = 加一行口径。
_Avoid_: 画面层（那是渲染层）、视频源（那指素材来源）

**平台预览基准**:
相机实时预览件相对录像文件是否已被相机插件镜像这一**设备事实**：应用能直接读到该事实时按读到的取值，读不到时按机型规则推导。
_Avoid_: 平台镜像（混称）、相机镜像（那指相机自身行为）

**平台保存基准**:
平台写出的录像文件相对原相是否带镜像这一**设备事实**：今日恒为原相（录像文件不携带翻转矩阵），仍作为可取值的位留在口径里。
_Avoid_: 文件镜像、保存镜像（同义，项目内统一本词）

**基准键**:
设备级私密键，取值 = 平台预览基准 ⊕ 平台保存基准，只进**相机预览行**，使「相机预览」与「片段回放」成为同一表达式（两路可见方向锚定平台保存基准）；不可随舞覆盖，可人工覆盖（设置界面入口尚未提供，在此之前按 `docs/basis-key-manual-override.md` 直接改设备级文件），不可推导时兜底为镜像。它是设备事实的落点，不是某支舞的练习选择。
_Avoid_: 校准值（口语）、机型校准（那是取得该值的过程）

**练习镜像**:
练习半区「画面方向」的用户选择（照镜子 / 原相）：设备级默认 + 随舞覆盖两层，作用于相机实时预览、练习片段回放与将来的导出文件；它是**视图选择**——不改变录像文件字节，也不改变素材方向。
_Avoid_: 镜像开关（与「全局镜像」混称）、局部镜像（那是源视频侧的片段集合开关）、练习侧镜像（旧称）

**全局镜像**:
整支视频的镜像开关（「全局镜像」工具，行为与旧「镜像」钮一致）：开启时画面水平翻转、不改源文件字节，与「局部镜像」互不代管。按视频持久化（公开标记文件 meta 段 + 视频索引缓存），点一下立即生效、不入撤销/重做史、不受锁定分段门禁。
_Avoid_: 镜像（单用含义含糊，已分全局/局部两层）、镜像开关（两个开关共用的混称）

**局部镜像**:
「局部镜像片段」是否参与画面反相的视频级开关（「局部镜像」工具，位于「全局镜像」右侧）：开 = 片段集合生效（区间内画面相对全局镜像反相）、关 = 片段整组不生效（画面从头到尾按全局镜像）。无任何片段时置灰，按一下提示「请添加局部镜像片段」；有片段时一点标黄、再点取消，与「全局镜像」同款。与全局镜像同存公开标记文件、随分享迁移，点一下立即生效（无「保存」）、不入撤销/重做史、不受锁定分段门禁。它是**视图开关**——表达"跟着参考视频转身"还是"一直面向手机练习"这一次练习选择，不改任何标注内容。
_Avoid_: 镜像开关（与「全局镜像」混称）、片段开关（逐片段开关已退场）、局部镜像片段（那是被它开关的区间对象）

**取景选区**:
一支舞**源画面**的取景取值：源画面上被圈中的矩形区域，四边按**源画面原相**归一化（与路径、容器、屏面无关）。它恒落在整帧之内、边不小于**取景控制点**抓得住的尺寸（屏幕 24dp 等效）；**没有它 = 未调过 = 整帧**，「复位」= 删除它。屏幕上的画面就是「选区内容按 contain 装进本态可用区」，故选区自己的宽高比就是上屏画面的宽高比；**取景后全仓的画面几何都按它算**（落位、**画面矩形**、**备注贴纸**与局部镜像标识），等于把选区里那一块当成重新导入的视频。一份选区由**普通编辑面**与**对比态源侧**共用，两条路径含义唯一。
_Avoid_: 取景带／取景基线（旧形状与旧参照系，已退场）、裁剪框（那改内容）、取景倍数、缩放参数

**取景控制点**:
**取景选区**上八个可拖点——四个角点（同时调两轴）与四条边的中点（只调该边）；边线本体不可拖。它们是改选区的唯一把手：框内拖动整体平移、框外拖动新圈一个、点上拖动调形；拖动一律**硬钳在整帧内**——贴到边即停、往回拖即随手指回缩。命中盒**逐轴**给足：`min(48dp, 该轴框长 ÷ 2)`，小框上随之收缩，保证框中央恒留一条能整体拖动的空带。
_Avoid_: 控制柄（那是轨道手柄带里分段线/首尾线的拖点）、把手（口语）

**取景调节**:
专门用来定源画面上屏范围——**取景选区**——的子状态（取景调节态），两条路径共用工具栏上的同一枚「取景调整」：普通编辑面（含待命态）进**单画面取景调节态**（画面就是源视频），**对比-控制层**进**分屏取景调节态**（只调源侧半区）。纪律：**进入即收起控制层、画面手势完全交给取景**——进态先显整帧（未调过时整体亮、无框无遮罩），第一次拖动圈出**取景选区**，其后框内拖整体平移、框外拖新圈、八个**取景控制点**调形，框四边**硬钳在整帧内**（贴到边即停、往回拖即随手指回缩）。取景只改显示（不改媒体流、不改录像内容、不改导出），**取景态内不出现任何缩放倍数读数**（视线留在画面上），退出三条同路——取景条的「完成」/系统返回键/点画面外（普通编辑面回编辑态、对比态回对比-控制层）。「复位」= 删除选区（等于"没调过"，回到整帧）。取景是**持久显示设置**：圈好的选区在整个打开期间常显于源画面——编辑态、观看态、对比源侧都按它渲染，拖动预览/暂停/循环/倍速照施；**备注贴纸与局部镜像标识钉在它们标的画面内容上**（出框时钳在画面内、屏幕尺寸不随取景缩放），**数拍浮层与节拍动画不参与取景**（几何按播放页视口）。
_Avoid_: 范围选取（口语，规格内统一取景调节）、画面设置（口语避讳）、裁剪（那改内容，取景只改显示）、取景器、取景基线／填满半区（旧参照系，已退场）

**取景条**:
取景调节态画面底部的那条操作带——标题「取景」＋提示「拖动圈选画面」＋「复位」＋「完成」（退出回编辑态或对比-控制层）；复位 = 删除**取景选区**（等于"没调过"）。落位与形制都是**不遮画面、手指不瞄准**的服务条件：底部居中、定高条（下限 60dp），整条尽量落在画面外的黑边里（横屏横向片源的分屏情形；竖屏、竖向片源没有下黑边时，条横向居中且不承诺不遮画面）；按钮触控区按手指尺寸给足，条宽与按钮位置在整次手势里一动不动（它只发命令、不读会话取值）。**提示放不下时**换到标题下一行、居中（条高随内容增高），不省掉提示。
_Avoid_: 取景面板（不在控制层里，是画面上的条）、取景条读数（已撤回，见取景调节）、复位两侧（旧文案，已退场）

**显示朝向**:
视频画面在屏幕上实际呈现的朝向；与文件里编码宽高所写的朝向可以相反（横向编码 + 旋转元数据的竖屏素材即如此）。**画面比例（宽/高）一律按显示朝向算**，不按编码尺寸算——播放页的画面落位与封面出图共用这一口径。
_Avoid_: 显示尺寸（同义的另一写法，统一写「显示朝向」）、源方向（未说明按编码尺寸还是显示朝向判）、编码尺寸 / 原尺寸（那是文件里的字节朝向）、竖屏源 / 横屏源（口语，须写明按哪个口径判）

**视口**:
App 此刻布局所用的逻辑矩形，宽高随**屏幕朝向**互换。它是布局与钳制取值的参照系，与 App 请求的**屏幕朝向**、与设备物理像素都不是一回事——物理像素须配上像素比才折成视口尺寸。
_Avoid_: 屏幕（单用泛指物理表面）、分辨率、设备等效视口（那是对某台机器量测口径的记录写法，不是基准）

**屏幕朝向**:
App 向系统请求的屏幕朝向，取值**竖屏**／**横屏**。非播放器页面锁竖屏，不受系统「自动旋转」开关影响；播放器进入时跟随设备，用户点一次**转屏钮**即粘性锁定到该朝向、本页内物理旋转不再改变它，离开播放页落回竖屏。它是 App 自己的请求，**不是会话取值**——「跟随／锁竖／锁横」由「App 请求了什么」与「系统此刻是什么朝向」共同表达，宿主不另存方向取值。
_Avoid_: 屏幕方向、设备方向、方向锁、屏幕姿态（那指视口此刻的形状）

**命中盒**:
可点区域**实际接收点按的矩形**——不等于视觉件的矩形。下限 **48×48 逻辑像素**；邻接密集区（可点域互相贴着、按 48 外扩必互吞的地方，如标注工具区槽位排）允许以 **44** 兜底，但每一处兜底都要在集中视觉 token 层的代价清单里点名，不许默认继承。达标靠**透明外扩**（把可点层撑到下限、视觉件居中其内），视觉尺寸与既有手感一律不变；矩形断言一律取命中矩形而非视觉件矩形。
_Avoid_: 触控目标（旧 44dp 指引口径，已被 48/44 取代）、点击区域（口语）、热区（实现层措辞，仅指被外扩的既有入口时用）、可点面积

**字号档**:
文本随不随系统字号缩放的两档口径：**语义档**随系统字号缩放（判据：读不到它会丢失信息），为此放开或按缩放重算所在盒子的排版容量；**装饰档**固定排版（纯装饰与刻度文本），注释必须写明不承载语义。两档共用一条纪律——量测与渲染两侧吃同一个缩放值（"量测与渲染同源"），不是把某一层单独缩放。
_Avoid_: 缩放档、大字号模式（那像全局开关；这里是逐处归档）、受控固定排版（旧机制名，曾指整棵子树关缩放）、noScaling（实现形态，不是档名）

**对比度下限**:
文字与它**实际压着的底色**（半透明前景先合成到底色再判）之间 **4.5:1** 的下限；不按主题 surface 算，算术唯一声明在 `lib/core/contrast.dart`。承载不达标处**只动承载可读性的那一层**——提高底衬不透明度，或改由文字自身的深色边缘承载；不把文字调白到失真，色相家族不动。
_Avoid_: 可读性（泛称）、对比度（单用未说明按哪个底色判时含糊）、WCAG 档（规范名，不是本表词条）
