# 舞库 — Context

一支舞作为练习对象的身份与读面——舞库的合并读、封面、舞级掌握状态，以及视频标识。

## Language

**视频标识**:
视频内容指纹（xxHash64，导入时后台计算、打开时校验）；打开时以「大小+文件名」先行匹配索引加速恢复，不一致按新视频处理。
_Avoid_: 路径、文件名（那是快速键，不是标识）

**舞**:
首页/统计/计划中的「一支舞」对象 = 一个已导入视频条目（video_id 为锚，卡片/详情/统计/DDL/事件关联均以其为对象）；「歌曲署名」只作它的显示标题，不构成对象本身。
_Avoid_: 视频条目（指底层导入索引条目，实现层用词）、歌曲署名（那是三元组标题，不是练习对象）

**舞库**:
本机全部「舞」（= 索引条目）及其合并读面：把每支舞分散在四处的数据合成一处——视频索引（署名缓存、文件路径、续播位置）、公开标记文件（有效区间、分段线→学习段）、本地文档（逐段熟练度、编辑偏好）、练舞统计（练习总时长、最近练习）；组员方案（导入得来的只读标注）是独立读面，详情页自用。卡片与舞详情要的派生量（熟练度百分比、完全掌握、平均练习遍数）在此按同一口径算出，一律取**我的标注方案**；封面默认取首线帧、可换成自定义帧。删除一支舞（连同它的练习素材与组员方案；练舞统计按时长保留）、改名（署名）、逐段改熟练度与一键完全掌握是它自持的管理写路径；跨舞聚合与日历事件不在其中。
_Avoid_: 视频列表（那是索引条目的机械枚举）、曲库（与「随舞曲库」混称）、首页（那是页面，不是对象）

**封面**:
一支舞在舞库里的画面标识：默认取**首线帧**（有效区间起点所在的帧），随首尾线调整而变；用户可换成自定义帧，换过之后不再跟随首线，也可恢复为跟随。封面帧的位置属**完全公开**（随我的标注方案分享与备份），封面图片本身是设备本地缓存。
_Avoid_: 缩略图（那指图片文件）、首帧（那是视频第 0 帧，不是首线帧）

**熟练度色带**:
舞详情「练习分布」图里按学习段铺在曲线背后的淡色区间，颜色取该段熟练度档位（与播放器段体着色同一个五档取色入口），段界做窄过渡，按段的真实时间铺位，没有学习段覆盖的时段不填色。练习量由曲线高度独立表达，与它无关。
_Avoid_: 段体着色（那是播放器时间轴上的同一套色，不是本图）、热度（本图深浅不表达练习量）

**完全掌握**:
舞级状态：全部学习段熟练度均为「掌握」时自动成立（派生状态，不另设持久化标志），也可经「标记完全掌握」一键置顶全部段并记日期（可撤销）；DDL 到期按它判定「按时/逾期」；达成后提醒静默，出现新目标即重新开启。
_Avoid_: 已完成（旧表述，语义同本词条）

**群区块**:
首页上的一块，全站唯一写全群名、群号与群二维码的地方：群名、群号、把群号复制进剪贴板的一枚按钮，与二维码本身。**下载页**不重复这些内容——安卓态只在页尾留一行链到它的文字，iPhone、iPad 与新版鸿蒙则在页面上直接给一个入群按钮。入群按钮与那行链接都落在 QQ 的加群页，与二维码指向同一个群。
_Avoid_: QQ 群（那是平台）、群二维码（那只是其中一件）、反馈区（它的用途不止反馈）、社群（外文直译）
