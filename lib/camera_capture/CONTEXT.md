# 对比与录制 — Context

对比练习与录制回看这一条链——对比态与它专属的工具、录制准备与起录点，以及练习素材与练习片段。

## Language

**对比练习**:
以「源视频 + 前置摄像头实时画面」同屏对比跟跳并支持录制回看的练习模式：从播放器控制层的「对比练习」工具进入对比态，对比态内可录制自己、把录制做成练习片段回看/截取。对比态有三个面——**对比-播放态**（分屏观看，常驻录制钮）、**对比-控制层**（对比态的编辑面）、**分屏取景调节态**（专门调源侧画面的子状态）。与「双视频对比」分家——对比已导入个人视频的功能入口归首页，另开切片。
_Avoid_: 对比播放（旧规划名，已改名）、双视频对比（那是首页入口的另一功能，未建）

**对比专用工具**:
对比态专属的标注工具区槽——现为**练习镜像**一枚（作用于练习半区当前显示的那一路画面：实时相机预览与练习片段回放同向，取值见「画面方向」词条）；与其它标注工具同排，身份与次序声明进对比槽集，不占顶栏也不占视频播放工具栏、不是气泡面板。取景不在此列——它是工具栏上的「取景调整」（见「取景调节」）。
_Avoid_: 画面设置（口语，规格内统一对比专用工具）、对比专用工具面板（旧的顶栏气泡落点，已作废）

**练习素材**:
对比练习每次录制产出的原始录像文件及元数据（所属舞、录制起始的源时间、素材时长、录制时刻）；属**媒体**，不占「可见性等级」，只在分享时按勾选进包；不入视频索引（不新增舞条目/节拍分析/续播语义），删除素材才删文件。
_Avoid_: 录像文件（只指文件本身）、素材（单用含义含糊）

**练习素材库**:
全部练习素材的本地档案：素材文件存私有目录、清单为全局私密文档（条目带所属舞）；素材不随其轨道片段删除或重叠清理而消失，库内删除才删文件；所属舞被删除时其素材一并删除。
_Avoid_: 素材轨（那是需求文档旧词=主视频轨）

**练习片段**:
练习素材在练习视频轨上的引用（带截取范围），显示于录制对应的源时间区间、位置固定不可拖动换位；点选即进入回看，可端点截取（吸附拍点）、删除；**删除（含随素材连带删除）即退出回看**——练习半区回落实时预览，不留悬空回看。删除片段≠删素材。
_Avoid_: 素材片段（易与练习素材混淆）

**练习视频轨**:
对比-控制层轨道带最顶的新轨道行，承载练习片段块；对比态用另一份行集（见「轨道行」），行序不在本表内穷举。表恒按源起点升序、两两不重叠（入轨与截取放宽同一套钳制）。**写面归属**：截取/删除都是一次标注编辑（入撤销史）；**录制入轨**与**素材删除连带**是**非历史写**——不进撤销史，也不被撤销抹掉（撤销只回退这次编辑碰过的那几条）。
_Avoid_: 练习轨（单用含糊）

**录制准备期**:
从按下录制钮到**起录点**之间的那段会话——前导回退播放（含节拍前导或秒制兜底）、录制钮显示准备态、点按即取消。准备期内不产出素材。前导的通用纪律见词条**前导**——录制准备期的前导锚点取**起录点**，拍点由派生网格按媒介播放位置取。

**录制武装**:
让编码器从「未武装」转为「正在写」的动作，发生在**录制准备期**之内、**起录点**之前。目的是让编码器在起录点那一刻已经在写，从而保证**起录点**那一帧必然落进素材。
_Avoid_: 预热（那是相机流预热，与本词条不是一件事）

**起录点**:
录制准备期的终点：素材与源时间轴的**唯一对齐锚点**——素材的**素材源原点**取这一刻的源位置，片段截取范围也以它换算。语义上素材从这一刻开始，尽管文件里它前面还可能有一段**前言**。取值：有选中段 = 段首（分段线恒落八拍点）；无选中段 = **当前相位下最近的八拍点**（可落在按下位置之前半个八拍内），早于有效区间头时钳到区间头。
_Avoid_: 起录时刻（措辞含糊，分不清指哪一个时间轴）

**前言**:
**录制武装**到**起录点**之间录进素材头部的那一段画面。留在素材文件里（**画面内容**不进片段定义、不参与对齐），作用是给武装到编码器真正在写之间的那段延迟留余量——余量够，起录点那一帧就必然被拍到。
**前言长度**是**练习片段**入点的换算量：片段入点 = 前言长度、出点 = 素材全长，于是片段范围正好从**起录点**开始；片段引用侧记的素材内容原点因此 = 起录点 − 前言长度（素材文件偏移 0 落在**录制武装**那一刻，而非起录点）。
