# 播放页 — Context

播放页这个组合根上用户看得见、动得了的那一层——控制层与轨道带、画面手势、浮层、循环与延迟、倍速，以及各工具入口的门。

## Language

**控制层**:
播放页全屏时唤出的编辑面覆盖层——顶部栏、轨道带（**轨道行**与**轨道片头**）、播放进度控件、**标注工具区**与各工具入口都在其上。它没有可独立写的开合布尔：展开位由当前会话模式派生（观看与取景调节态收起，编辑与待命态展开），进入**八拍矫正**或**段内倍频待命态**即自动展开并关闭气泡。
_Avoid_: 编辑界面、底部工具栏（那是**标注工具区**的旧称）、浮层（易与**可拖浮层**混）

**倍速步进**:
循环练习时按档递增的播放倍速：从起步倍速开始，每个倍率循环（按段或整片）每满每档遍数遍即加一个递增量，到封顶后回到起步倍速重来（默认起步 0.5×、封顶 1.0×、每档 3 遍、递增量 0.1）。在「**倍速气泡**」左栏**步进栏**里由预设行启用，启用后与手动倍率互斥。**步进不随舞**——每次打开一支舞一律未启用、遍数清零，运行期档位不写**倍速记忆**；预设与当前预设是设备级、跨视频一份。
_Avoid_: 自动加速、渐加速、递增倍速

**舞者词条**:
备注编辑器里代表一条「舞者名册」条目的可点名字（名字 + 代表色圆点）：**备注态**点一下即在文本光标处写下一次**点名**，**名册态**点一下即给这位舞者**选代表色**；新增走名册态左段的舞者输入框（回车与「新建」钮是同一条路径，只建人、不自动写入点名），建完自动弹出选色浮层。它是名册在编辑器里的呈现形态——既不是输入框，也不是一块面板。
_Avoid_: 名册面板（旧形态，已退场）、标签（那指点名渲染出的着色区间，不是可点对象）、名册项（口语）

**名册态**:
「备注编辑器」的一个模式（钮文案「名册」↔「返回备注编辑」）：左段输入框原地换成**舞者输入框**，单击词条由"插入点名"变为"给该舞者选代表色"，新建一位舞者后自动弹出选色浮层。与**备注态**（改这条备注的文本）互斥，一次只做一件事。
_Avoid_: 名册面板（已退场的独立面板）、名册编辑页、名册弹窗

**手势反馈浮层**:
播放手势作用期间叠加在画面上的临时视觉提示（进度拖动时的正中迷你进度条与时间、音量/亮度的正中横向滑条、三指跳转的短提示等）；纯提示、不承载交互，手势结束即消失或自动淡出。
_Avoid_: HUD、提示弹窗（那指交互组件，如循环提示/镜像询问）

**画面矩形**:
视频画面在屏幕上的实际所占矩形——源画面按 contain 装进当前可用区之后的可见画面范围（窄于可用区时两侧或上下留黑边）。竖屏编辑态里它就是贴着画面区下缘的那条**画面带**（黑区留在上方），或整屏居中的画面；对比态按半区各有一份（源侧、练习侧）。**取景生效时它描述的是选区内容上屏后的矩形**——选区自己的宽高比就是它的宽高比，一切按它取值的几何（**备注贴纸**、局部镜像标识、**取消区**、循环／续播提示卡）随之落在取景后的画面上。
_Avoid_: 视频区（那指留出黑边的可用区，不是画面本身）

**取消区**:
进度拖动期间**画面矩形**左上角起的一角：以该角为圆心、半径略大于常规关闭按钮触控目标的四分之一圆扇形。手指焦点进入该扇形即为待取消（进度浮层转警示色并提示「松开取消」），在此松开即取消本次进度调整——进度回到拖动起点，等于没调过；移出即恢复。只在观看态的全屏拖动里有此区，编辑态的进度微调无取消角。
_Avoid_: 取消按钮（那是可点交互组件，本区是手势语义区）

**系统手势让路区**:
屏幕四边内侧的一条带（顶 48dp、底 44dp、左右 16dp，与系统上报的手势内缩取大）：画面手势的**起手点**落在其中时，本次手势不认该边同轴的分支——顶/底 → 垂直（亮度/音量），左右 → 水平（进度拖动、三指跳转）；点按类手势与浮层手势照常。只判起手，拖动中途移进不算。
_Avoid_: 死区（那指完全不可用的区域，本区内的允许轴与点按类手势照常）、安全区（那是留白布局用语）

**让路轴**:
一次手势会话里因起手点落在**系统手势让路区**而被禁的轴（顶/底 → 垂直，左右 → 水平；屏幕极窄时可两轴同时被禁）。轴锁规则不变，锁到让路轴的会话整场无动作，不退化到另一轴。
_Avoid_: 禁用轴（易与取景/录制期的停用混淆）

**轨道行**:
轨道带内按纵向堆叠的一行——局部镜像轨/备注轨/学习段轨/节拍轨/轨道手柄带行。某态下**有哪些行、什么次序**由**行集**决定（对比态换用另一份行集）。**空轨亦常驻显示**（备注轨与局部镜像轨同款）。每行还带一段**轨道片头**短标签（见词条**轨道片头**）。**片头是行集之外的一列，不是行**。
_Avoid_: 素材轨（旧称，指轨道行本身）、轨道（单用含义含糊）、层级、track

**轨道片头**:
轨道带最左、位于时间轴**零点之前**的一列短文字标签——编辑态自下而上 `控制`（轨道手柄带行）/`节拍`/`分段`（学习段轨）/`镜像`（局部镜像轨）/`备注`，对比态 `节拍`/`分段`/`练习`（练习视频轨）/`备注`。它是**行集之外**的一列（不是行集里的第七行）：没有自己的行高，纵向只按该态行集的逐行行高与行间隙与所属行对齐。**随窗口平移**：随缩放/平移跟内容一起移动——默认全片视图下完整可见，平移到零点之后即滑出可视带不画，平移回开头之前又可见（不是钉在屏幕左边的侧栏）；它落在时间轴内容区之左、不侵占内容区，与内容之间有一条视觉分界。按在片头上等于按在带上空白（不选中、不拖动、不吸附任何内容）；例外只一条——片头在可视带内时，**轨道手柄带行**那一段让给**首线**控制柄（按在该行的片头上横拖移动首线），其余行与其余时机仍是空白语义。**标签集按态对齐行集**：行不在该态行集内就没有它的标签（对比态没有「镜像」）；标签只是显示文案，不构成**轨道行**的身份。
_Avoid_: 轨道标题栏、侧栏（那是常驻钉边的形态）、标签行（它不是行）、轨道名

**轨道手柄带**:
轨道带沿底边的操作横带，供分段线与首/尾线的"手柄"（底部拖点/端标）点选与拖动；吸附/缩放 dock 迁出后该带专用于线的调整与"单击启用衔接段"类操作，属轨道编辑区而非某条素材轨。
_Avoid_: 素材轨（那是轨道行本身）、dock 行（吸附/缩放迁出前的旧称）

**控制柄**:
轨道手柄带内分段线/首尾线的拖点：点按=选中（分段线）或选中端标（首尾线），横向拖动=移动该线；多条线密集时各柄的触控区互斥分区。用词口径：用户可见文案里叫**小把手**（如「点这根小把手选中它」「线上的小把手可以拖着挪」）；**控制柄**是文档内部的说法，不出现在文案里。
_Avoid_: 手柄（单独使用易与"拖动点/把手"混淆）、小横条（旧称，文案已改叫「小把手」）

**延迟播放**:
双指双击画面、或在编辑态点工具条「延迟播放」钮触发的卡拍进入（两种入口同款：先回播放态，再起预备）：**起点 = 当前相位下最近的八拍点**，预备 = **从起点前 N 拍连续播到起点**（画面、音乐、拍声照常），越过起点即起播。预备期显示第 0 个八拍顺数（0｜x），视频区正中的居中大数字与浮层数拍取同一份 `八拍号｜拍号`；越过起点起，**延迟锚**把数拍重定为 1｜1。网格未就绪（占位/异常）时无八拍点，按一个八拍标称兜底。
_Avoid_: 延迟倒计时（那是前导的一支显示，不是本词条）、延迟循环（旧词，指段循环）

**延迟锚**:
延迟播放越过**起点**后接管数拍的会话锚：起点即第 1 个八拍（1｜1），在**数拍锚点链**里的位置在录制锚之后、临时衔接段段首之前。它是**会话值、不落盘**，任一打断即撤销——引擎转停沿（暂停、播到尾、退后台）、任何 seek、唤出控制层 / 进对比态 / 进取景调节态、开始录制、再次触发延迟、离开播放页或换视频；音量、亮度、倍速与收起控制层**不**打断。
_Avoid_: 延迟锚点（易与「八拍锚点」混淆——后者是相位工具，不改数拍锚）

**循环范围**:
当前**唯一生效**的那一个区间循环范围，由三类循环源互斥产生、按固定优先级取一：**练习片段回看 > 临时衔接段 > 学习段选中**（任一路生效即清除其余，三者不会同时非空）。学习段一路 = 相邻选中段**合并**后的「选中首段段首 → 选中末段段尾」——多段相邻选中是**一个**范围，不是每段各一个；片段回看一路取该片段的源区间；临时衔接段一路取其自身范围。播放时的区间循环就作用于它，「进度拖出即取消」也以它为准。
_Avoid_: 循环区间（口语）、选中范围（泛指「选中了什么」，易与「学习段选中」混淆）、整片循环（那是播到视频尾的循环提示，与本词条无关）

**轨道设置条**:
轨道带外右上角、紧贴轨道带上方的设置横条，承载 预览吸附开关/锁定分段/轨道缩放条 等轨道相关设置，不占轨道带内内容区。
_Avoid_: 轨道工具条、轨道控制条（本表统一为轨道设置条）

**标注工具区**:
控制层底部承载标注编辑工具的槽位排——正常态 = 熟练度/重点/分段/**添加**/删除/自动分段（6 槽），待命态整排换成八拍锚点四槽。每个槽是一个**工具槽**（有标识、槽键与自己的动作）；某态下**有哪些槽、什么次序**由**槽集**决定（待命态、对比态、组员方案态各换一份槽集；对比槽集见「对比专用工具」词条，组员方案态见「组员方案」词条）。槽只声明自己有哪些**门**（装载未完成/无对象/锁定/网格未就绪/预览线越界），门之间的优先级与「不可用时长什么样、按下去发生什么」由唯一一处判定表决定——**装载未完成压倒一切（对象集本身来自尚未装载的文档，此刻「有没有对象」无从判定），无对象压倒锁定，锁定压倒未就绪与越界**：装载未完成时置灰但按得动、弹「正在装载」；没有作用对象时置灰但按得动、弹一句「该怎么做」（见词条「无对象」）；锁定期间置灰但按得动、弹「已锁定分段」，动作不发生；网格未就绪置灰且按得动、弹原因；预览线越界置灰且按不动。这五行归成一句契约——**灰着的入口按下去绝不执行动作，只可能告诉你原因**（「预览线越界」一态连原因也不给）：其中**无对象**一门的表现是置灰、可点、弹一句该怎么做（见词条「无对象」）。「添加」槽是**往时间线上落标注的入口**（创建三条 + 标记一条；点击向上弹出**添加条目**菜单，条目现为「备注贴纸」「局部镜像」「标记分段线」「半拍标记」（菜单文案 = 条目自己声明的标签，自上而下即此次序；「标记分段线」随选中线的标记现态改写为「取消标记」），未来继续加）：条目不是槽——不进槽集、不占那一排的宽度，但同样各自报门、同样由那张判定表回答表现与点击语义（「标记分段线」在未选中任何分段线时置灰但按得动、弹一句「该怎么做」）。
_Avoid_: 底部工具区（旧称，与顶栏工具区对称命名）、底部工具栏、工具栏、工具条、dock、槽位表（那是实现层用词）

**无对象**:
判定表第②门（见词条「标注工具区」）：这个动作没有作用对象 / 没有合法落点。表现为**置灰、按得动、点一下弹一句「该怎么做」**，动作不发生（每次按都弹，经词条「短暂提示」的胶囊浮层送出）。做法随入口自己声明，命中该门的入口一致对待：熟练度 / 重点 / 删除 /「添加」菜单里的「标记分段线」（「半拍标记」条目没有这一门，不受影响）；**刻意不给做法**的入口（待命态锚点三槽——它们的置灰是互斥的，此刻无话可说）仍按旧口径收场：置灰、按不动、静默。文案按**这支舞有没有分段**两态取辞——已有分段 → 指出要先选中作用对象（熟练度与重点是学习段、删除是分段线或练习片段、「标记分段线」是分段线）；一条分段都没有 → 指出更前面的一步（先用「分段」或「自动分段」切出段来），因为「没有作用对象」最常见的原因恰恰是还没切过分段，这时让人「先选中」是句空话。无对象压倒锁定：没东西可作用时先说他该怎么做，而不是告诉他「已锁定分段」。
_Avoid_: 不可用（那是判定表对「有门命中」的总称）、置灰项（那是表现之一，不是门）、无选中（只是「没有对象」的一种成因）

**锁定分段**:
轨道编辑的防误触开关（轨道设置条内那枚开关，显示「锁定分段·开/关」）：只锁**分段结构**——分段线的创建/删除/移动/步进与标记（flag）切换、自动分段的三档与「清空分段」、视频首/尾边界的调整（入口钮统一置灰、仍按得动：点一下弹居中「已锁定分段」短暂提示、动作不发生；拖动起手静默不参与、点选不受影响，首次位移成立时弹一次提示并放弃本次手势）；「删除」按作用对象判——选中的是分段线时同受锁，选中的是半拍线或局部镜像片段时照常可删。选中线/端标/片段不受锁，备注的文本与锁定开关同不受锁（备注的几何另受「内容锁」管，见词条），镜像两层开关（「全局镜像」「局部镜像」）与其余视图设置同样不受锁。
半拍线（插入/删除/移动/步进）、八拍锚点（添加/删除/清除）、节拍对齐与节拍倍频、局部镜像片段与备注贴纸/备注片段的建/删/移/端点拖、练习片段的截取与删除都**不受本锁**——它们各有自己的域，多步进入本身已经表达了明确意图。
_Avoid_: 锁定布局（旧称）、布局锁（口语）、锁编辑、保护模式

**短暂提示**:
状态或事件触发的短暂胶囊浮层（黑底圆角、纯提示不承载交互、点按穿透）：临时衔接段提示、三指跳转「已跳转」、锁定分段/步进启用确认、节拍未就绪提示、装载未完成提示、局部镜像无片段提示、对比拒录提示、浮层关闭提示、无对象做法提示（见词条「无对象」）等；既可全屏居中，也可贴到指定锚点**左侧、与它同高**——浮层落在锚点的竖向区间内、宽度钳在锚点左侧的可用空间内，浅底深字、一句话最多两行（引导用这一能力在备注编辑首次打开时指「名册」钮）；**定时自动消退**（停留 + 可选淡出），同一时刻只有一条，后触发者接管；作为**引导步**出现的那一支显示过即置位，此后再不自动出现。
_Avoid_: 手势反馈浮层（那是手势相位过程自带的视觉提示，如拖动迷你进度条/音量亮度滑条）、提示弹窗（那指交互组件，如循环提示/镜像询问；本词条成员一律无按钮、IgnorePointer）、**事件徽章**（按住 2 倍速徽章、段循环延迟占位、镜像历史提示等随事件条件显隐、无停留定时的胶囊件；它们与本词条共用胶囊视觉，但不是短暂提示）

**续播位置**:
上次离开播放器/切后台/暂停时记录、下次打开自动续播的播放位置（**完全私密**，存索引条目，不随任何分享包、随备份走）；记录与恢复共用同一条越尾钳制——位置不落自定义尾线右侧，越线记/钳回尾线内侧（恰在尾线不视为越线）；上次到尾视为从头（记录为 0）；位置在头部数秒内不弹「从头播放？」；恢复读取的尾线一律取 effective 派生时间线口径（时间线未初始化时整片兜底）。
_Avoid_: 播放进度（那指播放中随时变动的当前进度，不是跨会话恢复对象）

**倍速气泡**:
「倍速设置」工具与观看态右下胶囊共同打开的那一个锚定气泡，内容并排两栏——左**步进栏**、右**倍速栏**；横竖屏切换时两栏改上下堆叠。编辑态与观看态共用同一组件与同一开合状态。气泡里的倍率档位、滑条与历史列读写的是**倍速记忆**的生效值。
_Avoid_: 倍速设置气泡、步进气泡（旧称，指两个独立气泡）

**倍速记忆**:
一支舞的播放速度偏好的**随舞**归属：只有**手动倍率**一个值（本地文档 `prefs`，**完全私密**，不随分享包与组员方案流出、随**整机备份**走）；缺键 = 这支舞没有意见，即**出厂原速**——它没有设备级默认层，新导入的歌与任何从未调过速度的舞都以正常原速打开。开舞即把倍率写穿播放引擎，故第一遍就是这支舞应有的速度，不带上一支舞的速率；未识别身份时改动不落盘。**步进不随舞**：每次打开一支舞步进一律未启用、遍数清零，步进运行期的档位不写记忆。与**倍速历史**（设备级：最近用过的档，跨视频一份）和**步进预设**列表及其选中项（设备级，跨视频一份）分工——后两者是跨视频的习惯与资产。
_Avoid_: 倍速设置记忆、默认倍速（那会暗示存在设备级的默认层）、设备级倍速（旧归属）

**数拍锚点链**:
数拍数字、节拍动画与节拍声**选段**相对锚点的选择顺序：**录制锚**（录制阶段恒用起录点）→ **延迟锚**（延迟播放越过起点后的起点）→ 临时衔接段段首 → 选中学习段段首 → 播放位置之前最近的分段线（恰在线上以该线为新段段首从 1｜1 重数）→ 首线。前两级都是会话值，随会话结束或打断撤销。临时段生效期间锚点恒为临时段段首、整段连续顺数（跨触发线不重数），退出后回落本链。屏幕数拍数字与拍声选段读同一条链（同源）。
_Avoid_: 选中锚点（只指链上的段首两级：临时衔接段段首与选中学习段段首）、锚点（单独使用含义不明；本词条的锚点是**段首锚定**，与「八拍锚点」无关）、浮层锚点链（旧称，只提浮层）

**浮层位**:
数拍数字与节拍动画浮层的左上角偏移，按**姿态 × 对比**分四格各自记忆：姿态二值（横屏／竖屏，按播放页视口宽高判定；横屏两向共用一格、竖屏两向共用一格）、对比二值（对比 = 整段对比会话，含对比播放态／对比控制层／分屏取景调节态；其余一切非对比态为普通）。未自定义的一格 = **贴左、纵向视口高 12%**，按当前视口现算、不落盘；自定义值**存歌曲私密**。自定义值只钳在生效面显示，钳制结果**不回写**（转回原姿态原样恢复）。右上角工具「重置位置」只清**当前格**的位置，并附带把矩形宽系数与摆锤等比系数回 1.0（尺寸系数四格共用）。
_Avoid_: 坐标（只表达位置、未表达分格）、浮层位置（与备注贴纸按视频内容矩形归一化的贴纸几何混淆）

**可拖浮层**:
播放态叠加浮层的**家族词**——浮层底座承载一类可交互内容（现为 数拍数字与节拍动画、备注贴纸），共享一套交互语义：常态穿透、点选进入浮层选中态（青色虚线框 + 4 角工具）、选中态下**单指落浮层主体即拖动平移**、双指捏合缩放、右下**锁定钮**（宿主所有、各内容类共用）；**角工具与几何各随内容类而定**——每类自带自己的角工具语义，以及自己的参考系、钳制框与几何归属（存哪、随谁走）。同一时刻至多一个浮层处于选中态，点空白即清选中。数拍数字与节拍动画一类的现有取值：4 角工具为 左上 ✕ = 关闭浮层显示＝「节拍动画」总开关关、右上重置位置、左下节拍提示入口、右下锁定钮；矩形形态只改宽度、摆锤整体等比（两指任意位置起手都缩该浮层）；位置按「**浮层位**」分四格记忆、矩形宽系数与摆锤等比系数按形态分开记忆，**存歌曲私密**；尺寸上限联动播放页视口、位置钳制在屏内（角工具恒可达）、有最小钳制（过小不报渲染溢出）；右下锁定钮**不持久化**（每次进入选中态默认解锁）——这是它与备注的「内容锁」的区别（见词条）。
_Avoid_: HUD（纯展示词）、叠加层（过泛）、浮层缩放（那指手势，不是本组件名）

**拖动预览**:
拖动进度／预览线期间画面呈现目标时刻那一帧的形态（播放页全屏拖动、编辑态视频区微调、轨道带预览条与拖线、封面选帧页共用同一形态）：拖动期间画面定格在目标时刻那一帧，松手后由主引擎对落点做帧级精确 seek 并按手势前播放态恢复。它指画面，不指轨道上那条线。
_Avoid_: 预览条、预览线（那是轨道上的可拖线与播放头）、缩略图预览窗（那是在指示浮层上另开小窗的形态）

**转屏钮**:
请求**屏幕朝向**转为另一边的唯一入口，两处形态共用同一个动作名——竖屏编辑面画面区右下角的无字图标（动作「转为横屏」）、横屏编辑面返回键正下方靠左的文字矩形「转为竖屏」。它随控制层同显隐、录制中不出现、对比练习态共用；顶栏返回键与系统返回都不承担转屏。竖屏那枚对**显示朝向为竖的画面**同样可用。
_Avoid_: 旋转按钮、方向按钮、全屏按钮（那是另一件事）、竖屏播放（在播放器里会被读成播放控制）
