# 文档与持久化 — Context

两份文档（公开标记文件与本地文档）的形状与版本纪律——字段归属、版本谱系与迁移、读结局与留档。

## Language

**本地文档**:
与公开标记文件配套、仅存本地的 JSON（`local_<hash>.json`），承载一支舞的**小组公开**与**完全私密**两级字段——逐段熟练度、学习段选中、编辑偏好、浮层几何、练习片段列表、素材自动删除策略、**投屏准备记忆**（`prefs.castPrep`，见 [投屏](../cast/CONTEXT.md)）。它整份不出分享包，但可分享性按「可见性等级」逐字段定，其中熟练度可随勾选进包，其余只随备份走。
_Avoid_: 本地私密文件（旧称，名字与内容不符——它已含小组公开字段）、私密文件、local 文件

**文档地板**:
一份文档在首个发布版 v0.1.0 时的版本号——历史事实、声明一次永不改。它是版本谱系（地板 + 按序迁移步骤）的起点，也是唯一许可「读空」的凭据：低于地板的格式从未随发布落过盘，可丢；地板之上的一切版本判断只裁可写性、不改内容。写大了会把已分发格式标到只读，故有发布门的地板棘轮兜底。
_Avoid_: 起始版本号、最低版本（那像运行时兼容下限）、floor（外文直译）

**读结局**:
读一份文档得到的一等结果——**可写读**（文件不在、或沿链升到本版）或**只读读**（高于本版、低于地板、版本头读不出，原因具名）；只有可写读带写回入口，「覆盖一份没读懂的文件」由此在类型上不可达。版本判据只决定可写性、从不决定读空。
_Avoid_: 读取状态、读结果（口语，不点明可写/只读二分）

**留档**:
读到只读文档时把**原文按内容寻址另存一份**（幂等、写旁路文件、不占写链）——「忘记写迁移」的代价因此从丢用户数据降级为「写不回去，但读得出、还留了档」。留档失败 = 整次写回失败；不自动清理。
_Avoid_: 备份（那指整机备份）、快照、缓存副本
