# 投屏 — Context

把正在练的这支舞送到同一局域网上的另一块屏去看与遥控——投屏渲染与投屏副本、接收端与投屏会话、投屏态的两种面。

## Language

**投屏**:
把一支舞的**投屏副本**递给一台**接收端**自己播放、手机转而做遥控这件事的总称。它**不镜像手机屏幕**——手机上的界面不会上电视。
_Avoid_: 无线投屏（口语全称，主词就用「投屏」）、镜像（那指**系统镜像**那条别的路，本项目自己做不了也不做）、屏幕投射、Cast / AirPlay / DLNA（那指协议，不是这件事）

**接收端**:
同一局域网上接受推送、自己解码播放的那台设备（电视、盒子、投影仪）。
_Avoid_: 电视（那是其中一种）、大屏、屏幕、设备（太泛）、播放端

**投屏渲染**:
把当前设置与标注**烧进画面与音轨**、产出一份**投屏副本**的过程。渲染的是**画面类**（全局镜像、局部镜像片段、源画面取景、备注贴纸）与**呈现类**（数拍、节拍动画）与**声音类**（拍声）；**时间类**（分段线、半拍线、八拍锚点）不进画面——它们以「能跳到那一段」的形式留在遥控里。
_Avoid_: 渲染（单用会与「把控件画到屏幕上」混指；本上下文内可当简称）、烤制、烘焙、烧入（口语）、转码（那只是其中一步）、导出（那是**分享**域的词）

**投屏副本**:
**投屏渲染**的产物：一份自足的视频文件——画面已含镜像、取景、贴纸与数拍，音轨已含拍声，范围为这支舞的**首线→尾线**。它比源视频副本**多一代有损压缩**。
_Avoid_: 渲染产物、成片、导出的视频、缓存视频、临时文件

**投屏倍速档**:
投屏只认三个播放倍速：0.5、0.75、1；**一档一份投屏副本**，切换倍速就是让接收端换一个文件播——因此切换有起播等待，而倍速本身**不依赖接收端支持**。
_Avoid_: 倍速（那指播放页那条细腻连续的倍速）、倍速步进（那是率随时间递增的玩法，投屏态不支持）

**投屏准备**:
进入**投屏态**之前的那一段编排：选**接收端**、勾选要渲染的东西、选**投屏倍速档**、等**投屏渲染**、可取消。它发生在投屏态之外；取消即回到进它之前的样子、零副作用。
_Avoid_: 投屏向导、投屏设置页、准备页、投屏面板

**投屏会话**:
一次从推到断的连接，绑定一台**接收端**。它不写任何文档、不落任何标注；离开这支舞即结束。
_Avoid_: 连接、投屏连接、会话（单用）

**投屏态**:
播放页的**会话模式**取值族——**投屏-控制层**（编辑面：顶栏是投屏工具、底排槽位整排不出现、轨道带只留分段轨）与**投屏-观看态**（观看面：控制层收起，屏上只留一枚只作状态提示的**投屏胶囊**）。与编辑态、观看态、对比态并列。
_Avoid_: 投屏模式、投屏界面、遥控态、投屏页

**投屏胶囊**:
**投屏-观看态**下屏上那枚只读状态件，写明「投屏中 · 接收端名」。**它不接任何手势**（防误触），要操作就先点画面展开控制层。
_Avoid_: 遥控条、投屏条、悬浮球

**画面开关**:
**投屏态**里那枚把画面区从黑底切成**静音本地预览**的开关；默认关（黑底 + 一行指路提示）。预览**只画视频画面本身**——贴纸、数拍、节拍动画都不画（它们已在电视上），且不可交互。
_Avoid_: 预览、本地预览、同屏、画中画

**断开投屏**:
结束**投屏会话**的动作。投屏态顶栏有一枚具名工具，**左上角的退出箭头是同一动作的第二个入口**；两者都回编辑态。
_Avoid_: 退出投屏（同义，会与「退出投屏态」这一模式动作读成两件事——本项目里它们是同一次）、停止投屏、取消投屏

**系统镜像**:
手机系统自带的整屏无线镜像（Android 的「投屏 / 无线显示」）。**本项目不做也做不了**——第三方 App 无法自己发起它；投屏态顶栏那枚入口只把用户**送过去**（跳系统设置），且跳之前先**断开投屏**，免得电视上两份画面打架。
_Avoid_: 镜像（单用会与**局部镜像**、**全局镜像**混指——那两样是画面内容，会被渲染进**投屏副本**）、屏幕镜像、系统投屏、无线显示（那是系统里的叫法，词条主词用「系统镜像」）
