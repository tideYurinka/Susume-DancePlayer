# 投屏 — Context

把正在练的这支舞送到同一局域网上的另一块屏去看与遥控——投屏渲染与投屏副本、接收端与投屏会话、投屏态的两种面。

## Language

**投屏**:
把一支舞的**投屏副本**递给一台**接收端**自己播放、手机转而做遥控这件事的总称。它**不镜像手机屏幕**——手机上的界面不会上电视。
_Avoid_: 无线投屏（口语全称，主词就用「投屏」）、镜像（那指**系统镜像**那条别的路，本项目自己做不了也不做）、屏幕投射、Cast / AirPlay / DLNA（那指协议，不是这件事）

**接收端**:
同一局域网上接受推送、自己解码播放的那台设备（电视、盒子、投影仪）。
_Avoid_: 电视（那是其中一种）、大屏、屏幕、设备（太泛）、播放端

**投屏渲染**:
把当前设置与标注**烧进画面与音轨**、产出一份**投屏副本**的过程。渲染的是**画面类**（全局镜像、局部镜像片段、源画面取景、备注贴纸）与**呈现类**（数拍）与**声音类**（拍声）；**时间类**（分段线、半拍线、八拍锚点）不进画面——它们以「能跳到那一段」的形式留在遥控里。
_Avoid_: 渲染（单用会与「把控件画到屏幕上」混指；本上下文内可当简称）、烤制、烘焙、烧入（口语）、转码（那只是其中一步）、导出（那是**分享**域的词）

**投屏副本**:
**投屏渲染**的产物：一份自足的视频文件——画面已含镜像、取景、贴纸与数拍，音轨已含拍声，范围为这支舞的**首线→尾线**。它比源视频副本**多一代有损压缩**。范围用滤镜链**中段**的时间窗表达（`trim` / `atrim`）、**不用快速定位**——各闸门的时间窗判的都是源时间轴；因此**只勾声音类 + 1× 档**那条视频流原样复制的副本收不了范围，推的是整片（复制改不了长度）。
_Avoid_: 也别说副本里有**节拍动画**：**呈现类只烤逐拍静态数字**（摆锤与动画一像素都不进副本——烤死的动画与遥控跳段后的重锚定会互相打脸）。
_Avoid_: 渲染产物、成片、导出的视频、缓存视频、临时文件

**投屏缓存**:
本机盘上装**投屏副本**的那块渲染缓存区（ADR-0005）——应用私有目录下独立于练习素材与出站分享目录的一处；**全局有容量上限**，超限按**最近使用**淘汰（每支舞每**投屏倍速档**一份）。它的**占用与清空**在「详细设置」里那一行（清空要确认）；它**不进 susume 包、不随整机备份**，投屏期能拉到它只是**投屏会话**期内的局域网可达，不是新的可见性等级。
_Avoid_: 渲染缓存（省掉「投屏」会与封面取帧一类本机缓存混指）、缓存视频（那是**投屏副本**的避用叫法）、临时文件（它跨会话留着，不是临时物）

**投屏倍速档**:
投屏只认三个播放倍速：0.5、0.75、1；**一档一份投屏副本**，切换倍速就是让接收端换一个文件播——因此切换有起播等待，而倍速本身**不依赖接收端支持**。
_Avoid_: 倍速（那指播放页那条细腻连续的倍速）、倍速步进（那是率随时间递增的玩法，投屏态不支持）

**编码器性能点**:
系统逐台编码器声明的「保证同时做到多大尺寸、多少帧率」那条读数（Android 10 起；本仓 `minSdk` 24，故 API 24–28 的设备上问不到）。**投屏渲染**前问它一次，答案是**三态**：保证 1× 实时 / 不保证 / **问不到**——第三态按「不可保证」兜底（与不保证同一侧）。
_Avoid_: 编码能力、硬件指标（都太泛）、性能（单用会与「渲染快不快」的观感混指）

**渲染分辨率档**:
**投屏渲染**输出画面的一维（也是**投屏缓存**键的一维）：编码器**保证 1× 实时**就按**源分辨率**渲；**不保证**或**问不到**就降到 720p，并在**投屏准备**面板上当场说明「这台机器没法保证 1× 实时渲染」。只勾**声音类** + 1× 档时视频流原样复制，这一维不进命令行、也不出那句说明。
_Avoid_: 画质档、清晰度（都太泛）、分辨率（单用会与源片尺寸混指）、降级档

**投屏准备**:
进入**投屏态**之前的那一段编排：选**接收端**、勾选要渲染的东西、选**投屏倍速档**、等**投屏渲染**、可取消。它发生在投屏态之外；取消即回到进它之前的样子、零副作用（**用户改过的取值不算这段编排的副作用**——那是用户表态，变更即写**投屏准备记忆**，正是「关掉面板不丢」）。
_Avoid_: 投屏向导、投屏设置页、准备页、投屏面板

**投屏准备记忆**:
**投屏准备**面板那两个渲染勾选档与**投屏倍速档**多选**按这支舞**记住的取值。它落这支舞的**本地文档** `prefs.castPrep`——**不是设备级设置**：限定词是「按这支舞」，与节拍提示记忆、手动倍率记忆同层同款（换一支舞就换一份）；可见性等级是**完全私密**（ADR-0002）：不进 susume 包、随整机备份走。记录缺失、逐字段缺失、记住的档**已不在候选内** → **回默认并静默降级**（两个勾选档全选、倍速档取与手动倍率最接近的那一档），预置因此**至少留一档**、绝不落成空集合。它与**投屏缓存**互相不碰：清缓存不动它，改它不动缓存。
_Avoid_: 投屏偏好、投屏设置（那像设备级或泛指）、上次投屏（那像一份记录，不是取值）、投屏准备缓存（它不在缓存区里）

**投屏会话**:
一次从推到断的连接，绑定一台**接收端**。它不写任何文档、不落任何标注；离开这支舞即结束。
_Avoid_: 连接、投屏连接、会话（单用）

**投屏暂停**:
真正退到后台 / 锁屏那一刻**投屏会话**的形态——会话还在、**接收端被按停**（落在会话层，不是界面态）。**不引前台服务**，会话也不跨**播放页**存活。回前台时按**接收端上报**的状态续上：在播就追成播放态、暂停就追成暂停态且**不自动抢播**、已停 / 掉线走**断开投屏**那条既有失败收口，过渡 / 问不到一位不动；本机不自己记「刚才是不是我按的暂停」（接收端是权威）。
_Avoid_: 后台投屏、继续投屏（那是明确不做的前台服务那条路）、投屏挂起、暂停投屏（会与**投屏态**里的播放暂停读成同一件事）

**遥控项**:
**投屏态**里那几枚作用于**接收端**（而不是作用于本机）的既有控件——**进度**（画面横向拖动与帧步进）、**播放暂停**（底排播放键与双击）、**音量**（右半屏纵向滑的滑条），现共三枚。它**不是一套新界面**：落位就是这三个既有控件（见 [播放页](../player/CONTEXT.md) 的「控制层」与「手势反馈浮层」）。
**哪几枚显示由一处判据回答**：**遥控项判据**（`CastRemoteControls`）按接收端上报的**当前支持传输动作**，与起投探测那一次**读不读得到音量**（有端点且答得出 `GetVolume`）逐项给出「显不显示」。探测不到 / 探测失败 / 设备确实不支持三者收敛到同一个出口——**不显示**、静默降级；判据说「不显示」的那一枚，遥控**一条都不发**（界面与写入路径问的是同一处，不各自另判）。**倍速不走这条判据**（它靠一档一份**投屏副本**换文件，不依赖接收端能力）。非**投屏态**没有遥控项这一说——那三枚控件恒在，行为逐位不变。
_Avoid_: 遥控条、遥控面板（都不存在这样的件——遥控项落在既有控件上）、电视端控件（那是接收端自己的界面，不归我们管）、远端控件

**投屏态**:
播放页的**会话模式**取值族——**投屏-控制层**（编辑面：顶栏是投屏工具、底排槽位整排不出现、轨道带只留分段轨）与**投屏-观看态**（观看面：控制层收起，屏上只留一枚只作状态提示的**投屏胶囊**）。与编辑态、观看态、对比态并列。
_Avoid_: 投屏模式、投屏界面、遥控态、投屏页

**投屏胶囊**:
**投屏-观看态**下屏上那枚只读状态件，写明「投屏中 · 接收端名」。**它不接任何手势**（防误触），要操作就先点画面展开控制层。
_Avoid_: 遥控条、投屏条、悬浮球

**画面开关**:
**投屏态**里那枚把画面区从黑底切成**静音本地预览**的开关；默认关（黑底 + 一行指路提示）。预览**只画视频画面本身**——贴纸、数拍、节拍动画都不画（它们已在电视上），且不可交互。它自己**不持屏幕唤醒**：投屏期那一份常亮由投屏态那一侧单持（见下一条）。
_Avoid_: 预览、本地预览、同屏、画中画

**屏幕常亮**:
**投屏态**里这一屏不自动熄灭这件事。投屏态的画面区被投屏画面覆盖件换掉——连源画面件都不挂，播放内核那份「画面件持着」的唤醒因此没有持有者，屏幕照常熄灭；于是投屏侧在**进投屏态**那一下自己持一份（与画面件同一条平台能力），**离开投屏态**即放——释放收在投屏会话的**既有复位一处**（**断开投屏** / 换视频 / 离开播放页都经它），不新写退出点。持有是**引用计数**式的：重复持有只拿一次、计数归零才真的放开；投屏态画面区挂上那一帧的帧末还会**再确认一次**（退场的源画面件在同一帧收尾时会放开同一个平台开关，而那个开关不是引用计数的）。**不引前台服务**，也不因此让投屏比播放页活得久。
_Avoid_: 唤醒锁、wakelock / WakeLock（实现里的叫法）、防熄屏（口语）、后台常驻（会读成另一件事——本项目明确不做）

**断开投屏**:
结束**投屏会话**的动作。投屏态顶栏有一枚具名工具，**左上角的退出箭头是同一动作的第二个入口**；两者都回编辑态。
_Avoid_: 退出投屏（同义，会与「退出投屏态」这一模式动作读成两件事——本项目里它们是同一次）、停止投屏、取消投屏

**系统镜像**:
手机系统自带的整屏无线镜像（Android 的「投屏 / 无线显示」）。**本项目不做也做不了**——第三方 App 无法自己发起它；投屏态顶栏那枚入口只把用户**送过去**（跳系统设置），且跳之前先**断开投屏**，免得电视上两份画面打架；系统投屏设置接不住时退到**显示设置**、两级都不接给一句**短暂提示**。**投屏准备**面板「搜不到接收端」的空态里放的是**同一条入口**（同一个动作、同一份代价说明）。两条路的代价差由那枚入口自己的提示文案承担。
_Avoid_: 镜像（单用会与**局部镜像**、**全局镜像**混指——那两样是画面内容，会被渲染进**投屏副本**）、屏幕镜像、系统投屏、无线显示（那是系统里的叫法，词条主词用「系统镜像」）
