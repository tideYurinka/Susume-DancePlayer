# 标注 — Context

一段视频上被标注出来的东西与它们的编辑纪律——分段线与学习段、备注与舞者名册、半拍线、自动分段，以及标注写入的唯一入口。

## Language

**分段线**:
用户在时间轴上划分**学习段**的位置标记，贯穿轨道：位置是时间轴上的绝对时间点，恒落在**八拍点**，只能在**首尾线**划定的有效练习区间内创建与拖动。默认细线，经「添加」菜单的「标记分段线」置位后成粗线（见词条**分段线标记（flag）**）。线身单击即选中（再点取消、异线替换，不影响**学习段选中**），拖动一律经**控制柄**。
_Avoid_: 分隔线、裁剪线（本项目不剪视频文件）、切割线（那是**自动分段**产出的同类线在本表里的专名）

**学习段**:
**首尾线**与**分段线**实时算出的派生几何（不落盘）：未创建分段线时没有学习段；有 n 条分段线即 n+1 段，首段左端点为视频首、末段右端点为视频尾（两端不可拖动），相邻两段首尾相接、总长恒等于有效练习区间时长。段属性按段序另行存储——逐段熟练度在**本地文档**，重点与**段内倍频**在**公开标记文件**；选中态见**学习段选中**。
_Avoid_: 学习段片段、段落（口语）、章节

**舞者名册**:
按视频保存的舞者列表，每条含名字（单字/两字简称，如「果、鸟、海」——圈内单字名常见，照录不误）与代表色；不跨视频关联。由用户**手工维护**（增删名字 + 选代表色，在备注编辑器的「名册态」里做），写入为**直写**：不入撤销史、不受锁，与歌曲署名编辑同侧。在备注编辑器里以「**舞者词条**」的形式呈现。它描述的是**参考视频里被点名的人**，与「组员方案」的组员是两回事。
_Avoid_: 角色、标签、组员、队员（后两者指「组员方案」里给你发方案的队友）

**首尾线**:
标注轨道两头那两条可拖动的边界线，两条线之间就是**有效练习区间**——练习只认这一段：圈外部分不参与分段与循环，练舞统计与循环范围都以其为准。经**控制柄**拖动调整范围；封面帧默认跟随头线。
_Avoid_: 裁剪线（本项目不剪视频文件，只圈练习范围）、播放范围、练习区间（单用含义含糊，统一「有效练习区间」）

**临时衔接段**:
在分段线上点选即启用、以前后各 1 八拍为范围的临时循环练习段（可跨相邻学习段、按首尾截断、起点按八拍点取整），用于练段间衔接；与学习段选中互斥、几何变化自动清除、不落盘不进熟练度。
_Avoid_: 衔接练习（那是用途描述）

**选中域**:
不入史的选中态的总名：**标注选中**的单值槽与**学习段选中**两族同属其中——都不进标注编辑的撤销/重做史，其中学习段选中跨会话保留、单值槽只是编辑期界面态。

**标注选中**:
轨上标注对象（分段线、半拍线、视频首尾端标、局部镜像片段、备注片段）的单选槽——单值、点其它标注即清除；它是**选中域**的单值槽一族，与**学习段选中**并立。
_Avoid_: 选中域（那是两族的总名，本词条只指单值槽）

**学习段选中**:
**选中域**中跨会话保留的一族：一支舞当前被选中的学习段集合，**非空时恒为连续的一段**，段数从一到全部段数；它既是三类循环源之一（与「临时衔接段」「练习片段回看」互斥，见「循环范围」），也是熟练度、重点与**段内倍频**的作用对象，由段体的单击或长按圈选产生（单击落在已选中的段上即整体清空）。**完全私密**，落本地文档 `session` 段、跨会话保留。
_Avoid_: 激活、激活范围（泛指「生效的是什么」）、激活组（口语）、选中（单独使用泛指任意标注对象的单值选中）

**内容锁**:
单条备注自己的锁（存公开标记文件、随分享走），语义只有一句：**保护这条备注的几何**——贴纸的位置与大小、轨道片段的整体移与端点拖被拦（提交被拒绝并弹提示；拖动手势起手即静默不参与）；文本与锁定开关**豁免**（防误触的目标是拖动，写字不容易误触发）。与「锁定分段」（全局、私密、只管分段结构）是两把不同的锁、互不代管；锁定后仍可点选、角工具仍可用，再点锁角即解锁（锁是保护不是锁死）。
_Avoid_: 锁定分段（那是全局防误触开关，另一把锁）、浮层视图锁（既有可拖浮层的锁定钮不持久化，与本词条不是一回事）

**标注编辑**:
对标注（分段线/半拍线/首尾边界/flag/熟练度/重点）的一切修改统一经其发生的入口——自动分段落线、节拍对齐的整体线平移、八拍锚点的添加/删除同经此入口；一次标注编辑 = 时间线写入 + 段序键属性级联 + 选中维护 + 学习段选中与临时段按几何变化清除 + 撤销/重做记录，这五件事同为一步、不可分割。落点解析（对齐落点）与锁定分段门禁同属这条入口的纪律：交互命令一律吸附到落点并受锁定门禁，恢复装载与撤销回放例外；恢复装载（重开/换视频载入持久化标注，非撤销语义）与换视频/重开复位也经此入口。
_Avoid_: 编辑协调（那是机制词）、编辑会话（撤销/重做的历史措辞，非概念名）

**歌曲署名**:
每段视频一个歌曲署名 = 可选版本舞者 + 歌曲名 + 可选版本注记三元组（三元组是真源，显示串 `「版本舞者」歌曲名 - 版本注记` 只是它的呈现）；随公开标记文件分享，标记文件未创建前以索引里的署名缓存承载；与「舞者名册」「备注贴纸」三者并立。
_Avoid_: 歌名（那是三元组中的字段）、标题（顶栏显示，未署名时回退文件名）

**对齐落点**:
各标注线无条件对齐的固定网格（不再提供可调密度/可关闭的「吸附网格」）：首尾线拖动/步进吸**节拍网格拍点**（覆盖内；覆盖外与异常态自由）；分段线插入/拖动恒**八拍点**（仅就绪网格派生，见词条）；半拍线插入/拖动/步进恒**半拍格点**（相邻拍点中点，占位均匀网格照常派生）；临时衔接段起点按**八拍点**取整（就绪网格）。
_Avoid_: 网格点（旧词：可调密度/开关的吸附格点，已不提供）、网格线（那是渲染刻度/视觉）

**半拍线**:
用户手动插入的半拍位置标记：经「添加」槽的菜单选「半拍标记」（菜单文案 = 半拍标记，库内概念名仍为「半拍线」）落在节拍网格派生的最近半拍格点（**相邻拍点中点**，不含拍点本身）；插入后可在节拍轨行内点选、拖动始终吸半拍格点、步进跳相邻半拍格点；支持像分段线一样选中后经标注工具区「删除」删除（一次标注编辑、可撤销）；视频属性公共标记，随公开标记文件落盘、可分享。半拍视觉只有用户插入线一种——节拍轨与矩形节拍动画都不画自动半拍刻度（"半拍细分"仅作为节拍声的**半拍段**存在）。
_Avoid_: 半拍刻度（指自动实时细分刻度，已不画）、哒拍标记（人工节拍修正，见「节拍矫正」）、插入半拍（那是旧入口钮名，现为「添加」菜单里的条目）

**局部镜像片段**:
局部镜像轨上可持久化的**区间**片段（[startMs,endMs) 半开、钳在视频首尾区间内，随公开标记文件分享）：**没有启用开关**——片段覆盖当前显示位置且「局部镜像」为开时，该区间画面相对全局镜像**反相**（显示镜像 = 全局镜像 ⊕ (局部镜像 ∧ 任一片段覆盖当前位置)，位置即真值，暂停/步进/拖动定格同判；该式即「画面方向」词条里源视频面那一行的取值）。创建 = 从「添加」槽的菜单选「局部镜像片段」，在播放头处默认一个八拍宽、起点吸八拍点、自动钳入首尾/截断防重叠，且若「局部镜像」当前为关则一并打开（新建即生效）；单击 = 只选中（供删除与拖动）；端点吸附真实拍点（占位均匀网格同级派生、异常网格自由）；建/删/移/端点都是一次可撤销的标注编辑。局部镜像轨常驻显示（空轨亦然）。与「备注片段」是**结构统一、语义不统一**的关系：两轨的区间块同形、视觉取值同源；而**不重叠规则刻意不对称**——镜像片段不重叠是因为"镜像是一个状态"（同一时刻只能有一个值），备注片段不重叠是因为"一行内要可读"。不得按一边「统一」掉另一边。
_Avoid_: 镜像区间（同义但项目内统一「局部镜像片段」）、局部镜像（那是视频级的开关，指片段对象时用本词）、片段启停（逐片段启用已退场）

**备注贴纸**:
备注的双形态对象——轨道**备注轨**上一段**时间窗**片段 + 画面上一层文字贴纸，一一对应；它同时是「可拖浮层」的一个内容类。数据（时间窗/文本/锁定/贴纸几何）全部进**公开标记文件**，随文件分享还原——与既有可拖浮层的「几何存本地私密、锁定不持久化」刻意相反。贴纸**只在播放头落于其时间窗内时出现**（与播放/暂停无关；控制层展开时窗内只读常显、完全不参与交互）；几何（位置/大小）只在窗口内的播放态可调、按**视频内容矩形归一化**（分享跨分辨率可还原），受「内容锁」门禁。四角工具 = 左上删除 / 右上开编辑器 / 左下跳转控制层该片段 / 右下「内容锁」开关。文本是**单行标签**：正文恒白，其中的「点名语法」按舞者名册代表色着色；**描边恒开、颜色由底色派生**（浅色描黑边、深色描白边；**点名段**底色为纯白时描白边、并在这层白边之外再加一层更细的黑边，好让白色舞者的点名与正文分得开——正文恒为白字黑边），因此备注自身没有颜色可调。三处入口（新建即弹 / 轨片段选中后再单击 / 贴纸右上角）进**同一个**编辑器面。同一时刻只存在一条备注。
_Avoid_: 备注（那是改名弹窗的版本注记字段，不是本词条）、可拖浮层（那是家族词，指载体时用本词）、画面浮层（过泛）

**备注片段**:
备注轨上与「备注贴纸」的时间窗等宽的**区间**片段（[startMs,endMs) 半开、钳在视频首尾区间内、按起点升序且两两不重叠，随公开标记文件分享）：框内**显示这条备注的文本**（与贴纸同源——隐藏点名语法字符、点名按代表色着色；框内放不下即省略、连省略号也放不下就不显示内容——默认缩放下时间线看全片，一个八拍只有十几像素宽，因此多数时候看不到文字、放大才显出）；**单击 = 选中**并在该片段上方展开这条备注的内容（内容超出片段范围是常态）、**再单击 = 打开备注编辑器**；长按 = 切换「内容锁」；整体拖 = 平移时间窗；端点拖 = 改时间窗起止（触控范围在两端向外扩展、与相邻片段或屏幕边缘冲突的部分不给；选中后给端点柄、触控范围更长）。建/删/移/端点都是一次可撤销的标注编辑（受「内容锁」门禁），拖动落点吸附拍点、被相邻备注与视频首尾互斥钳制（**钳空静默停住**——与「创建落点被占则转编辑」这条出声路径刻意不对称）。
_Avoid_: 备注（同「备注贴纸」的避讳）、片段（单用已被「局部镜像片段」「练习片段」占义，第三义一律写全「备注片段」）、控制柄（那是轨道手柄带里分段线/首尾线的拖点，与本条的端点柄不是一回事）

**时间窗**:
一条备注的存在区间（半开 `[startMs,endMs)`），决定「这条备注什么时候在画面上出现」：默认一个八拍、起点吸**自由区间内**的最近**拍点**（每个拍点都是合法起点，不按八拍分级；网格未就绪时用占位格估算宽度、不吸附但照常创建）；播放头落于窗内即显示贴纸、窗外即消失。同一时刻只存在一条备注（时间窗两两不重叠、按起点升序），因此两个贴纸**不可能同时可见**——「贴纸面积重叠」在本设计下不存在。
_Avoid_: 区间（过泛）、片段（那是轨道上的呈现对象，时间窗是它的数据）

**点名语法**:
备注文本里对一位舞者的一次点名：写法为 `@` + 名册里**确实存在**的名字（最长优先）+ 紧随其后的一个空格；三个部分构成一个不可分的语法单元，渲染时 `@` 与那个空格**不显示**，名字按其代表色着色。名字必须在名册里才构成点名，所以普通文字里的同名单字（如「如果」的「如」）永远不会被着色；打错的点名删掉那个 `@` 即恢复为普通文字。文本是点名的**唯一真源**——不另存字段、不存下标、不存快照，渲染时按当前名册解析，故名册的增删改色会实时反映到既有备注上。
_Avoid_: 标签（口语，且与渲染出的着色区间混指）、引用 / refs（旧机制名：独立字段 + 下标区间 + 保存时匹配，已退场）、提及（外文习惯，项目内统一「点名」）

**自动分段**:
「自动分段」工具菜单产出的分段线序列及其**切割线**口径：点槽向上弹出的三档菜单——**清空分段 / 4 个八拍/段 / 8 个八拍/段**（三项都立即执行、不二次确认，各自是一次可撤销的标注编辑）。后两档 = 自动设好首尾（首/尾 = 网格首/末拍）并自**整曲第一个八拍点**起算，**每段 N 个整八拍区间**一条切割线（N 由档位给出；半八拍区间**不占配额**）；配额满点若恰好落在半八拍区间的左端，切割线**顺延到该半八拍区间的右端**（于是那一段 = N 个整八拍 + 半八拍，半八拍归其前面那一段）；**八拍锚点处强制一条切割线并清空配额**（锚点即新段起点，其后重新数 N 个整八拍）；锚点密集时接受 1.0／2.0 等短段，不设最短段限制；末段不足 N 个八拍并入最后一段、收在尾线；切割线只落在首/尾线开区间内。八拍锚点改变八拍点后，切割线随之重算。**替换时既有段数据不丢**：旧分段线上置位的 flag 迁到时刻最近的新切割线（无距离阈值、距离并列取更早那条、同一条新刀只置位一次；落在新首/尾区间外的丢弃）；逐段熟练度与重点按旧新分段的**时间重叠**就地重写——新段熟练度取与之相交的全部旧段中的最高档、重点为「任一相交旧段为重点」，旧分区里不存在对应段的段序丢弃（分区为空即整体清空）。自动产出的切割线**不是三指跳转的目标**——三指只跳标记过的分段线（见词条**分段线标记（flag）**）。
_Avoid_: 分刀（非正式说法，本表统一「切割线」）、每 32 拍（旧口径；无锚点时它等价于 4 个整八拍区间）

**清空分段**:
删除全部分段线的标注编辑动作（学习段几何归零 → 整片范围练习）：首/尾线与半拍线保留，熟练度/重点重置为缺省（自动分段两档改按几何重写、不重置；见该词条）；一步可撤销。现居「自动分段」菜单三档之一。
_Avoid_: 清除分段（本表统一「清空分段」）、重置分段

**分段线标记（flag）**:
分段线上置位的进度标记（用户可见文案里叫**标记**）：粗线显示，随公开标记文件分享、可被「锁定分段」拦住，置位与取消是一次可撤销的标注编辑。「添加」菜单里的「标记分段线」条目作用在**选中的那条线**上，文案随现态在「标记分段线 / 取消标记」间二选一。它也是**三指跳转的唯一目标**——三指左右滑只跳标记过的分段线，滑动方向上没有标记线就回退视频首/尾；标记被拖动或被「自动分段」替换迁到新切割线后，跳转目标随之改变。
_Avoid_: 三指跳转（那是用法，不是这个标记）、flag 线（粗线是它的呈现，不是另一种线）、分段线标记（易读成「给线段做的标记」）

**重点（学习段）**:
学习段的星标标记，位于段体左上角（右上角位置已废弃），随公开标记文件分享、一次标注编辑可切换；与学习段选中、熟练度无关。
_Avoid_: 收藏、星标（仅指图标本身）

**熟练度档位**:
