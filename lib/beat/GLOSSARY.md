# 节拍 — Context

节拍的识别、人工修正、呈现与发声——节拍网格与八拍点、节拍矫正、数拍与节拍声、音画同步。

## Language

**前导**:
锚点之前 N 拍的回退播放段：从「锚点 − N 拍」连续播到锚点，前导区显示**第 0 个八拍顺数**（0｜x），进入锚点后转正式数拍。锚点按场合取**起点**——循环前导取段首、录制准备取**起录点**、延迟播放取**延迟起点**，三者都落在**当前相位下的八拍点**上（分段线恒落八拍点，故循环前导的段首天然满足）；正因如此，前导区的**白数就是普通状态在该位置的真实拍号**（N=4 → 5…8，N=8 → 1…8），青数固定 0。共同纪律（三处一律适用）：拍点一律由**派生网格**按媒介播放位置取（唯一时钟，不保留独立自由计时器）；**一拍只有一声**——前导与正式由**节拍呈现**的同一条求值产生，不存在两个发声者；异常态（无节拍网格）按秒制兜底且不显示节拍器/数字/声。
_Avoid_: 前导倒数（数拍是第 0 个八拍顺数，不是 4-3-2-1 倒计时）、提前量（那是音画同步的延迟值）

**循环前导**:
学习段/临时衔接段每遍段循环到段尾后，自动 seek 回「段首 − N 拍」处连续播放的前导设置（不前导/2 拍/4 拍/8 拍，默认 4 拍）：前导区播段首之前的动作画面 + 节拍声 + **第 0 个八拍顺数（如 N=4 → 0/5、0/6、0/7、0/8）**，进入段首后从 1｜1 正式数拍；异常态（无节拍网格）前导按秒制兜底且不显示节拍器/数字/声；与整片"循环提示"的八拍延迟相互独立。档位与默认值不变；设置入口在首页「详细设置」的「预备拍数」一组（设备级、作用于所有舞），旧「延迟循环」字段已退场。前导的通用纪律见词条**前导**（本词条是它在段循环场合的具体设置）。
_Avoid_: 延迟循环（旧「段尾静帧等待」语义，已废弃）、循环延迟（易与整片循环提示的延迟混淆）、前导倒数（数拍是第 0 个八拍顺数，不是 4-3-2-1 倒计时）

**节拍轨三态**:
节拍轨的可用状态：就绪 = 真实节拍网格已落盘（按**节拍网格**绘制刻度与强拍强调）；占位 = 分析中/未开始（整行不定态进度条——持续流动的光带、不表达百分比——行内居中「节拍分析中……」，不画均匀占位刻度）；异常 = 分析失败（整行暖色底、行内居中「节拍识别失败」，不画假刻度、节拍相关功能停用、计时类走秒制兜底）。三态都是不可点的纯显示；就绪交接无「分析完成」过渡，刻度出现即交接。分析失败不弹提示。
_Avoid_: 降级（那是通用措辞）、无节拍数据（那是自动分段菜单的就绪门提示文案，不是状态名，也不是节拍轨行内文案）

**节奏源**:
向全部消费方回答「节拍轨现在什么态、N 拍有多长、这件依赖节拍的事此刻能不能做」的唯一来源：三态（见词条**节拍轨三态**）落到网格值上的**性质**（就绪/占位/异常 ⇒ 真实/占位/秒制兜底），加上由它推出的时长。可用性只有两个谓词——**真实拍点可用**与**秒制兜底**；时长是**三条具名基准**且互不相通：**八拍标称**（8 × 拍长；占位与异常都得 4 秒）、**前导档位**（异常态**档位数字即秒**，2→2s、4→4s、8→8s）、**名下单拍**（一拍多长，拒录阈值的取值）。八拍标称与前导档位恒差 2 倍，通用「N 拍时长」不得用来表达前导。不落盘、与模式无关。
_Avoid_: 节拍器（那是发声面）、节拍 seam / 网格 seam（实现层用词）、网格（见词条**节拍网格**）、节拍源状态（与词条**节拍轨三态**重复）

**节拍网格**:
全部节拍消费方所见的拍点序列（时刻 + 强拍标志），即公开标记文件 `beat` 段的拍点表——它是**节拍规整**的产物，只此一份；识别拍点不落档、产品内不可读。「节拍对齐」「节拍倍频」「八拍锚点」三条人工修正在它之上派生（整体平移、重采样、重定相位），不改写它本身。
_Avoid_: 网格（泛称，指数据本体时用本词）、识别网格（识别产物见词条**识别拍点**）、原始拍点（旧词，已退场）

**节拍规整**:
节拍分析在识别之后、拍点落盘之前做的一次等时化：逐段把拍距等时化成该段匀速，**相位偏差不超过预算**（当前 25ms）；真实相位跳变与短促变速按预算自动断段或直通，不被抹平。规格不合（拍点过少、非严格递增等）时整条原样落盘——规整绝不导致分析失败。落盘后不再重算。
_Avoid_: 平滑（实现期用词）、量化（那是取整）、抹平（那是无预算的规整，本词条明确不是）

**识别拍点**:
节拍识别（DBN 解码）直接产出的拍点序列，时刻落在解码帧率栅格上（fps=100 → 10ms）。它是节拍规整的输入，规整后即被替换，产品内不留档、不可读。
_Avoid_: 原始拍点（旧词，已退场）、真实拍点（该词在节拍相关可用性谓词里指「非占位 / 非兜底」，不指本词条）

**八拍点**:
从节拍网格派生、手动分段线插入/拖动的唯一合法落点（仅就绪网格；占位/异常无八拍点、分段入口置灰不可用）：自**相位原点**起按 downbeat 全局序数分组、序数为奇数者的时刻；相位原点默认 = 网格首个强拍，并可由「八拍锚点」**分段重定**（锚点自身即八拍点、其后每隔一个强拍一个八拍点，管到下一个锚点之前；锚点之前保持自动相位）。与轨道刻度「八拍大线」、节拍动画八拍首同源（见「节拍矫正」）。临时衔接段起点、**延迟起点**（延迟播放的起点与无选中段录制的起录点）按八拍点取整。一切用到八拍点的场合一律按**当前相位**（含「八拍锚点」的重定相）求值，不存在绕开锚点的第二口径；网格未就绪（占位/异常）时无八拍点，那是定义域退化而非某种可选口径——延迟因此走各自的既有兜底（录制准备按秒制、延迟播放按一个八拍标称），不另开第二套相位。
_Avoid_: 大线（那是轨道刻度称谓）、格点/网格点（旧「吸附网格」词，已不提供）、无锚八拍点（不是并列口径，是同一条规则在网格无锚点时的退化）

**音源段**:
一个音源＝一个音色，含若干**速度组**；每个速度组是同一语速下的一整套 9 段音频——号 1..8 的整拍段 + 1 段**半拍段**（用户标记的半拍点专用；仅「半拍声」开时、在用户插入的半拍点发声，节拍轨/动画不自动出半拍），每段自带**段内拍点标记**。哪一拍响哪一段由**选段**决定。新增音源 = 注册表加一个音源；人声/歌姬等未提供内容的音源维持「待支持」置灰。
_Avoid_: 声种/声音种类（已统一为「音源」）、音源=单一采样（音源是速度组的集合）、重音段/轻音段（那不是段类别——重音是所选段自己的身份，见**重音（节拍声）**）

**速度组**:
同一音源在某一语速下录的一整套 9 段音频；身份 = 该组**最长一段**的时长。**选速** = 在「最长段不超过**节拍网格**名义一拍」的各组里取最快一组，全都超过则取最慢一组；倍速不参与，播放轴一条时间轴只选一次、**音画同步校准会话**按会话档自己的间隔另选一次；换速不重载样本。
_Avoid_: 采样率 / 音质档（那是资产自身的属性）、速度档（易与倍速混）、BPM（那是网格的读数）

**段内拍点标记**:
一段音频内部该段「听感拍点」相对段首的偏移（毫秒）——排程发声时让标记时刻对齐视频拍点时刻；段首即拍点的短敲击采样标记≈0，带音头（铃/人声等）的采样标记为其听感音头偏移。标记是音频资产属性（随音源注册表记录），不是用户设置。

**选段**:
一拍响哪一段的唯一规则：前导区（八拍号 0）按拍号；**音效类**音源恒按拍号；**按号发音类**音源在拍号 1 时按八拍号（回卷 1..8）、其余按拍号；半拍点恒**半拍段**。八拍号与拍号取自**数拍**——屏幕数拍数字与拍声读同一处派生，故听到的强弱恒等于看到的 `八拍号｜拍号`。
_Avoid_: 段类别策略（旧的三分支策略）、选音色（那指音源）

**重音（节拍声）**:
节拍声的强拍层，不是一种段类别而是**所选段自己的身份**：**音效类**音源的号 1 与号 5 是重音资产，**按号发音类**音源则是「八拍号」那一段。落点 = 数拍的拍号 ∈ {1,5}，即**八拍点**与四拍中线、也就是**节拍网格**的小节首；**八拍锚点**、选中段、录制锚、延迟锚改变数拍即改变重音落点，与屏幕数拍数字同源；**节拍倍频**改的是网格本身，重音随新网格的小节首走。**前导**期走同一条选段规则（`0|1`、`0|5` 也是重音），没有例外。
_Avoid_: 强拍（那是轨道刻度的层级称谓，含大线与中线）、八拍大线重音 / 段首重音（旧口径）、重音段（重音不是段类别）

**节拍呈现**:
一次求值在屏幕与耳朵两处的呈现：屏幕上的**数拍**数字与**节拍动画**（含摆锤、录制准备与延迟预备的居中大数字）和耳朵里的**拍声**，是同一次「媒介位置 → 当前拍」求值的两个投影，不是各推一条的平行链。它向全部消费方回答「此刻数拍到哪了、该响哪一段」；**位置是它唯一的时间真相**——拖进度、段循环与整片循环回跳、换网格、换音源、进出**音画同步校准会话**都只是位置或它读到的一组设置的变化，不构成需要另行声明或另行重建的事件。**前导**是它在「位置在锚点之前」时的形态，**校准会话**是它换用会话档均匀间隔与墙钟位置时的形态，两者与正式数拍走同一条求值。与**节奏源**分工：节奏源回答「网格什么态、N 拍多长、这件事此刻能不能做」，节拍呈现回答「此刻数拍到哪了、该响哪一段」；网格、相位与数拍锚的读法不变。
_Avoid_: 声音模块 / 节拍声模块（那只是它的发声面）、节拍器（旧称，只指发声面）、拍点时间轴（旧接入形态，已退场）、不连续（节拍声）（旧接入形态，已退场）

**节拍提示面板**:
「节拍提示」设置面（两处入口：「节拍提示」工具与观看态数拍浮层选中态角工具；打开方式为入口旁**锚定气泡**，与倍速/步进/音画同步等锚定气泡互斥单开、屏内钳位）。气泡内容三段并排（窄视口放不下并排时改上下堆叠）：节拍动画＝总开关＋（开时）矩形/摆锤形态；声音反馈＝总开关＋（开时）**音源 ▾**（锚定可展开列表、项数组化可扩展；人声/歌姬「待支持」置灰不可选）、半拍声、音量（文字标注＋滑条＋百分比）、**视频静音**（音量滑条下方的「关闭视频声音」一项）；节拍矫正＝标题＋一行小字＋竖向三个按钮（节拍对齐／八拍矫正／节拍倍频，各带一行使用提示小字）的**菜单列**——本列只放三个入口，控件本体各自迁出（节拍对齐与节拍倍频的控件落在独立锚定气泡，气泡内另有「对特定段落设置倍频」一枚入口（进**段内倍频待命态**），见词条；八拍矫正进控制层待命态，见词条）；本列比另两列**窄**，提示一律用短句（如「整首偏移时用」「八拍点错位 / 半八拍时用」「识别快/慢一倍时用」）。组总开关关闭即收起本组子行——只变高度、同排各栏宽度不变；无「对齐试听」。不含前导开关（前导归「循环前导」胶囊）也不含独立的「节拍显示」总开关。本面板前两列里的总开关、形态、音源、半拍声五项按**节拍提示记忆**随舞取值；音量仍归设备级，**视频静音**既不随舞也不落盘（见词条）。面板不暴露「记忆值 / 设备默认」这两层——用户看到的永远是生效值。
_Avoid_: 节拍器设置（那是设备级 metronome 字段的混称）、节拍提示工具（与入口钮混淆）

**节拍提示记忆**:
一支舞的节拍提示偏好的**随舞**归属：动画总开关、动画形态、声音总开关、音源、半拍声这五个值随这支舞存（本地文档 `prefs`，**完全私密**，整份不出分享包与组员方案、随**整机备份**走）。**视频静音**不在这五个值里——它是会话值、不落盘。它只回答「这支舞要不要、长什么样」，与**节拍器设置**（音量所在、设备级）分工——音量是「这台设备该多大声」，不随舞。逐字段可无意见：两个总开关无意见即关（它们的默认**不随历史值浮动**，出厂态恒关）；形态/音源/半拍声无意见即取该字段的设备级当前值（设备级那一层由此只是**新舞的默认**，且只被用户的设置动作改写，系统路径不碰）。自动置开只发生在**真实网格就绪**时——新分析成功落定，或打开一支盘上已有节拍数据、却从没有过记忆的舞；置开即写记忆，一个舞最多一次，用户手动扳动也算他的表态、此后不再自动置开。
_Avoid_: 节拍器设置（那是设备级 metronome 字段的混称，含音量）、节拍默认（口语，未区分记忆值与设备默认）、观看偏好（过泛）

**节拍矫正**:
对节拍网格的人工修正总称（入口 = 节拍提示面板第三列菜单列），下辖三个动作：**节拍对齐**（整条数据整体 Δ 平移）、**八拍矫正**（以「八拍锚点」分段重定八拍相位）与**节拍倍频**（整条数据的拍密度按 2 的幂缩放、强拍与八拍点随新拍周期重定，见词条）。八拍矫正是一次性低频操作：按下即**自动展开控制层并关闭节拍提示气泡**，进入**待命态**（预览线恒定吸附最近强拍、不受「预览吸附」开关影响），标注工具区整排换成「设为八拍线／取消八拍线（两者互斥置灰）／清除所有八拍线／退出八拍矫正」；点击即落盘（原子写、写完立即刷新预览、一个锚点 = 一次标注编辑 = 单步可撤销、**无「应用」**），仅真实网格就绪可用（占位/异常置灰）；收起控制层或返回首页即退出待命态（锚点不丢）。
_Avoid_: 节拍修正（旧泛指）、校正（错别字）、节拍报错（旧拟名）

**八拍锚点**:
用户在节拍轨上标定的一个**强拍**（八拍大线或四拍线；一拍小线不可标），落地即自该点**重定八拍相位**——锚点自身为八拍点、其后每隔一个强拍一个八拍点，管到下一个锚点之前；锚点之前保持自动相位（= 网格首个强拍），**锚只向后延续**，既有分段线不迁移。用途 = 修正机械识别的奇偶错位（半八拍等）：如八拍点 1/3/5/7 之后音乐出现半八拍，把第 8 个强拍标为锚点，其后即 8/10/12…。存公开 markers `corrections` 段的**强拍序号**数组（与「节拍对齐」Δ 正交，Δ 平移不甩掉锚点；「节拍倍频」修正时按倍率**就地重写序号**——快方向原强拍全部落在新强拍集上、时刻与「它是不是八拍点」的判定都不变，慢方向落不到新强拍的由既有规范化丢弃，那正是识别给多了的伪强拍）。轨上视觉**仅待命态可见**：锚点所在强拍以第二色**大线**（几何同普通八拍大线、只换色）+ 轨顶同位圆点呈现，且该处**不画八拍数小数字**（数字仍占段内序号）；非待命态完全按派生层级画普通大线（锚点不可见）。
_Avoid_: 锚点（单独使用与「数拍锚点链」混淆）、八拍线（按钮文案「设为/取消八拍线」，指该锚点本身）、相位原点（那是派生内部的求值起点）

**节拍对齐**:
对整条节拍数据作整体时间平移的修正：平移量 Δ（秒）写入公开节拍段字段（非破坏、落盘拍点不动、可反复调可归零），派生网格时刻 = 落盘拍点 + Δ；「应用」时把已落盘的分段线/半拍线/首尾线整体平移同一 Δ（一步撤销、越界钳制）。档位：1 拍/½拍/10ms。其控件自「节拍矫正」菜单列进入后落在**独立锚定气泡**（与「节拍提示」气泡互斥单开，锚同一入口；关闭气泡即弃未应用的预览偏移）。
_Avoid_: 移相（外文直译，产品内统一节拍对齐）、节拍校正（错别字，与「节拍矫正」混淆）

**节拍倍频**:
对整条节拍数据作**拍密度**缩放的修正：档位五档 2 的幂（×¼ / ×½ / 原样 / ×2 / ×4），取值 = 派生拍数 ÷ 落盘拍数（即「数拍速度倍数」），写入公开标记文件的人工修正段（非破坏、落盘拍点不动、可反复调可归零）；派生拍点 = 落盘拍点按倍频重采样（快方向插等分中点、慢方向按**原首个强拍**定相位等距抽样），**强拍与八拍点随新拍周期重定**（新强拍 = 自原首个强拍的派生序号起每 4 个派生拍一个），故数拍、节拍声、各类吸附落点、前导与延迟时长、音画同步歌曲档、四拍桶格全部随之变化。入口 = 「节拍矫正」菜单列第三个条目，控件本体落在**独立锚定气泡**（与「节拍提示」气泡互斥单开、锚同一入口）：档位读数 + 「快一倍」「慢一半」+「重置」+「确认/取消」，按一下只改预览（节拍轨刻度实时变），关气泡即弃、确认 = 一次标注编辑 = 单步可撤销并退出气泡；仅真实拍点可用（占位/异常置灰）。已落盘的分段线/半拍线/首尾线**时刻不动**（它们的键是时间不是拍序号；快方向下旧半拍线的时刻恰是新拍点，只做发声去重）；「八拍锚点」的序号随修正就地重映射；练舞统计的桶明细不改写，由读取时按记录时的倍频投影到当前桶格。它是**整曲档**——单个学习段的档位见词条**段内倍频**，某处的**生效倍数 = 整曲档 × 该段段内档**。
_Avoid_: 节拍缩放（外文直译）、倍速（那是播放速率）、拍率（易与「会话网格」的歌曲节拍档混称）、粒度（口语，指档位本身）、全局倍频（口语）

**段内倍频**:
一支舞里某个学习段自己的节拍倍频档，与「节拍倍频」（整曲档）并列为节拍矫正的第四条人工修正：档位**只有两档** ×½ / ×2，外加「回到原样」，**按绝对档存**（派生拍数 ÷ **节拍网格**拍数）；某段的**生效倍数 = 整曲档 × 该段段内档**（没有段内档的段即整曲档），故调整整曲档时各段一起伸缩、段与段的相对间距不变。段内派生拍点 = **节拍网格**拍点按生效倍数重采样，段首即该段**第一个强拍**（段首恒为**八拍点**、也恒是拍点，故该段的数拍与重音一律自段首 1｜1 起）；段尾不是整拍时收在段尾前最后一拍，段外一律回到整曲档。它只改**怎么数拍**：数拍数字、节拍动画与节拍声、各类吸附落点、前导与延迟时长、段内八拍数全部随生效倍数走，而**四拍桶与练舞统计不随**——记账单位恒为整曲档的桶格。存**公开标记文件**（与学习段重点同侧，随「我的标注方案」分享；只读的**组员方案**里不生效），键是**段序**、只写非原样档；**分段几何变动**按既有三条先例重烘焙（自动分段按时间重叠、范围变化与插线/删线按段序重映射、清空分段即清空），重烘焙与几何改动同为一次标注编辑。入口 = 「节拍倍频」气泡里的「对特定段落设置倍频」，按下即关气泡进**段内倍频待命态**（见词条）。
_Avoid_: 局部倍频（旧拟名）、段倍率（与倍速混称）、独立倍频（口语，规格内统一「段内倍频」）

**段内倍频待命态**:
调**段内倍频**的会话态，形态照八拍矫正那套：它是 `PlayerSessionMode` 的一个取值（编辑面、无进入前置、控制层展开由取值派生），进入即关「节拍倍频」气泡；底部标注工具区整排换装为三枚**赋值**钮——**快一倍 = 把选中的每一段设为 ×2**、**慢一半 = 设为 ×½**、**回到原样 = 设为 1（清除该键）**，故多段档位不一时按一下即整片统一；三枚钮在**没有选中**时置灰但按得动、弹一句「先选一段再点这里」（**无对象**门口径）；**回到原样**在选中的段本来就全是原样时**保持可点**（按下无变化，与整曲档的「重置」一致）。作用对象 = **学习段选中**的**全部段**（与熟练度、重点同一作用对象）——点轨道学习段即选中并循环它，段的**位置与范围**由此直接对上时间轴，不需要另列一份段清单。每段改动各自一步撤销、边改边生效；退出三路（收起控制层／返回首页／换视频）与八拍矫正相同。不看**节拍提示记忆**。
_Avoid_: 段内倍频气泡（那指「节拍倍频」气泡里的入口）、局部倍频模式（口语）

**八拍数**:
两个相关但不同的计数：① 节拍轨八拍数标注——真实网格就绪且存在学习段时，对可视窗口**整窗一次判定**：窗口内相邻八拍大线最小屏距足够则窗口内全部显示、否则全部不显示（严格两档）；显示在未被分段线/首尾线占位的八拍大线上方的小数字（与大线纵向留间隙不重叠），编号为**所在学习段段内相对**（段首八拍 = 1、跨段重数；同位大线不显示但占序号；**八拍矫正待命态下八拍锚点所在大线也不显示小数字**——该处画锚点圆点——但仍占序号）；② 段内八拍数——学习段内居中淡字显示的该段八拍个数（就绪网格；**段首、段尾均落在八拍点上才显示**；按八拍点区间**加权**——整八拍区间 1、半八拍区间 0.5，故**允许 0.5 分度**，如「4.5 个八拍」；窄段按实际文本宽两级缩：全句 → 仅数字 → 隐藏）。① 的编号规则与「数拍」的八拍号/拍号格式均**不引入 0.5**（半八拍处只让下一根大线、下一个八拍号提前到来）。
_Avoid_: 拍号（指矩形格内 1–8 与数拍的白色小字）、八拍号（指数拍两数里的青色大数，段首锚定 1 起）

**四八拍循环（数拍）**:
数拍八拍号的显示循环：每 4 个八拍一组，八拍号 = (相对八拍−1)%4+1（段内 1–4），相对八拍超过 4 时八拍号旁加小上标组序（第 2 组起，如第 5 个八拍显示 ²1）；仅显示层循环，底层计数与锚点链不变。前导第 0 个八拍计数（0|x）不受影响。**有八拍锚点时二者不再严格同步**：数拍按八拍点顺数（半八拍让下一号提前到来），自动分段则在锚点处另起一段、半八拍顺延并入其前面那一段，故半八拍之后数拍循环与段界会错开。
_Avoid_: 轮次（与练舞「遍数」易混）

**节拍音量**:
节拍声的响度设置：声音反馈组内滑条 0–100%（默认 50、设备级字段），实际响度 = 该歌曲响度自动均衡基准 × 滑条增益（50% = 基准、100% = 基准×2），作用于所选的段与**前导**提示（半拍段另带内部响度拉平）。响度基准按歌曲自身响度每歌测量一次并本地缓存。
_Avoid_: 音量（那是播放手势调的系统媒体音量，另一回事）

**视频静音**:
把正在练的这支视频的声音关掉、只留节拍声的开关：节拍提示面板「声音反馈」组内**节拍音量**滑条下方的「关闭视频声音」一项。它是**会话值、不落盘**——换视频或离开播放页即回有声音，关掉「声音反馈」总开关也一并解除；它只静这支视频本身，**节拍音量**与系统媒体音量都不动。
_Avoid_: 静音（单独用易与「系统媒体音量为 0」混）、关声音（口语，未区分关的是视频还是节拍声）

**音画同步**:
针对输出设备音频延迟的补偿设置：延迟值（±1000ms，正 = 声音晚到、视觉按声音对齐）按音频输出设备分开存取（手机扬声器、某蓝牙耳机等各一项，未知设备归「其它设备」），存设备级私密。入口 = 「音画同步」工具（「节拍提示」紧左），打开即进入**音画同步校准会话**（见词条）——会话内调节的是试听值，「应用」才写入当前设备延迟值。经音频偏移 + 节拍声触发时刻平移（嗒声提前 Δ）共同生效，符号以真机听感校准。**补偿的目标是轨上刻度**：节拍轨刻度保持表示视频时间轴、不随 Δ 平移，数拍数字/节拍动画/摆锤也不随 Δ 平移，声音按 Δ 提前，使听到的拍点落在刻度的同一墙钟时刻。输出与引擎管线自身的固定偏移是另一回事，不混进 Δ。
_Avoid_: 音视频延迟（同义外文直译）、节拍对齐（那是网格相位与音乐重拍的整体平移，另一件事）

**音画同步校准会话**:
打开「音画同步」工具即进入的自足 A/V 校准会话：进入即暂停播放（记住进入前播放态、退出还原），气泡内 8 格拍点刻度带闪亮（固定于会话网格，见词条）与真实滴答声（走节拍声引擎的会话模式）同步呈现——低延迟输出下闪亮与滴答听感重合，高延迟蓝牙耳机可明显听出滴答偏晚；拖延迟滑条/细调会话试听值 Δ 到听感重合，点「应用」才写入当前输出设备的延迟记忆值并退出（取消/关闭气泡/切其它工具/退后台/会话中手动恢复播放 = 丢弃试听值）。切后台即停止；无闲置超时。
_Avoid_: 矫正会话（本表统一「校准」）、边播边听校准（那是批五旧方案，已取代）

**会话网格**:
音画同步校准会话自带的等拍拍点时间表：BPM 三档 = 歌曲节拍（当前曲目已提交节拍网格的拍周期）/ 120 / 160，默认歌曲节拍（无已对齐网格或无法得稳定等拍 BPM 时歌曲档不可用、回落 120）；自会话启动起算、重音每 4 拍、不含半拍点与用户半拍线；闪亮显示在网格拍点上，滴答发出时刻 = 网格拍点 − Δ（嗒声提前 Δ，与播放侧同一符号口径）；BPM/Δ 变更自下一拍生效。
_Avoid_: 节拍网格（见词条；那是曲目对齐数据，另一对象）
